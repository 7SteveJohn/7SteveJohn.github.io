FileButler · 本地智能文件管家

“隐私，深不可测。整理，快如闪电。”

把文件整理与本地知识库问答合二为一。完全由本机 Ollama 离线开源大模型驱动，无需任何 API Key，数据永不出本机。支持 Everything 式秒级搜索语法、新文档自动向量化（BGE-M3）、图片语义 OCR 与三级哈希查重清理，每步移动均有日志且全程可撤销。

研发理念

为什么坚持做这样的软件？

01

本地优先 (Local-First)

数据和算力应当完全掌握在用户手中。FileButler 将视觉大模型、文本嵌入与全文搜索全部置于本地运行，零外部网络请求，断网亦能完整工作。

02

极简克制 (Lightweight)

坚决拒绝动辄几百兆的 Electron 臃肿打包与后台驻留窃取数据。桌面端倾向原生的 Win32/C# 架构；Android 端做到零网络权限申请。

03

源于真实痛点 (Crafted)

不写无意义的玩具 Demo。每一个工具都必须在日常高强度使用中经受考验——从降低射击游戏的输入延迟，到机房弱网下的 CLI 命令速查。
