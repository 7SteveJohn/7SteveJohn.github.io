FileButler · 本地智能文件管家

“文件乱成一团？让本地 AI 帮你收拾。”

整理文件和本地知识库问答，合在一个软件里。AI 用的是本机 Ollama，不用 API Key，文件全程不联网。能秒搜文件、自动索引新文档、按内容搜图片、找出重复文件——每一步都有记录，手滑了也能撤销。

Python 3 Vue 3 + Naive UI SQLite / FTS5 Ollama 本地 RAG

GameBoost · 开打游戏前点一下

“对枪总掉帧？先点它，再进游戏。”

打 CS2、瓦、三角洲之前点一下就行。跑分不重要，解决两件事：对枪瞬间的掉帧和输入延迟。电源、GPU、网络这些设置它自己调好，不想要了一键全部还原。

GameBoost-DLSSG · 游戏优化与帧生成

“给老显卡，补上 40 系才有的帧生成。”

量身打造的游戏优化 + 帧生成二合一：一键切到适合游戏的状态，还能给 RTX 20/30 系开上 40 系专属的 DLSS 帧生成。电源、调度、GPU、网络全自动调好、全部可还原；实测《赛博朋克 2077》从 135 帧到 190 帧。
