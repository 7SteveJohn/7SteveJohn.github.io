技术底色与开发原则

不随波逐流，追求克制、可用与长久稳定。

01

本地优先与隐私 (Local-First)

数据必须留在用户自己的机器上。比如 FileButler 的 AI 能力完全依赖本地 Ollama 大模型与本地 SQLite 向量库，零 API Key 依赖，断网也能正常运转。

02

极致轻量与零权限 (Lightweight)

拒绝动辄几百兆的 Electron 臃肿安装包。桌面端倾向于 C# / Win32 原生可执行文件与轻量 pywebview；移动端 NetOps 做到完全不申请 INTERNET 网络权限。

03

为真实场景死磕细节 (Crafted)

每个项目都源于真实痛点。比如 GameBoost 专注压低竞技游戏 1% Low 帧生成时间抖动；NetOps 整理 500+ CLI 命令方便在机房断网环境下随身速查。
