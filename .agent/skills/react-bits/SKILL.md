# React Bits · Creative Component Integrator

You have access to the **react-bits.dev** design component ecosystem created by David Haz. Whenever aesthetic polish, landing headers, dynamic text effects, or interactive micro-surfaces are required, leverage react-bits patterns.

## 1. Catalog Lookup Guide
- **Hero & Headline Enhancements**:
  - `BlurText`: Animate letters fading in with blur easing.
  - `ShinyText`: Apple-style continuous subtle light glimmer sweeping across text.
  - `DecryptedText`: Cyberpunk/Matrix style text scrambling on mount or hover.
- **Atmospheric Backgrounds**:
  - `Hyperspeed`: Three.js / WebGL high-speed warp drive lines for gaming/tech headers.
  - `Squares`: Subtle moving grid background for developer tools.
  - `DotGrid`: Interactive particle grid.
- **High-Touch Interactive Cards**:
  - `SpotlightCard`: Dynamic radial gradient following mouse coordinates inside card bounds.
  - `TiltedCard`: Perspective 3D tilt tracking cursor distance from card center.
  - `StarBorder`: Neon light border traveling along SVG stroke perimeter.

## 2. Implementation Protocol
- For vanilla JS / HTML setups, extract pure CSS keyframes and SVG stroke transitions.
- Maintain lightweight bundle size and ensure graceful degradation if WebGL is unsupported.
