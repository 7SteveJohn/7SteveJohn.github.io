# 视频原声音频律动接入 · 交付记录

> **交付日期**：2026-11-05  
> **核心目标**：将背景音乐播放器中成熟的「Web Audio 频段分析与节拍包络（window.__BEAT）」能力全链路扩展至产品介绍视频（`#products video`），使视频播放时，其原声（旁白、音效、BGM）能实时驱动背后的 3D 神经网络/Cymatics 球体律动与视频视窗的外框环境微光。

---

## 一、设计动机与交互逻辑

在此前的站点中，背景 3D 神经网络粒子球与 Cymatics 驻波仅由左下角/顶部的音乐播放器（`js/player.js`）驱动。当用户播放产品介绍视频（如 FileButler、拍案、NetOps、Fluxion）时：
- 为了避免声音冲突，互斥机制会暂停背景音乐；
- 但此时视频的原声音频未接入 Web Audio，导致 `window.__BEAT` 归零，背景原本灵动的 3D 粒子球与连接网格瞬间静止，视窗也失去动感。

用户提议：「这个音乐律动，我感觉也可以给你播放介绍视频的时候也加上」。
这一建议将原本孤立的「视频演示」与「全站 3D 推理场/声学谐振背景」无缝串联，形成极高质感的视听合一体验。

## 二、架构实现与信号链设计

### 1. Web Audio 音频图复用与多源连接（Multi-Source Audio Graph）

现代浏览器的 `AudioContext.createMediaElementSource(el)` 对同一 HTMLMediaElement 只能调用一次，且必须妥善连接 `DestinationNode` 以保证扬声器正常发声。

我们在 `js/player.js` 中重构了音频图建立机制：
- **`ensureAudioGraph()`**：单例初始化 `AudioContext` 与 `AnalyserNode`（FFT 大小 2048，采样率自适应，非对称频段划分）；
- **`connectMediaSource(el)`**：安全守卫机制，首次播放时为 `<video>` 创建 `MediaElementSourceNode` 并挂载于 `el._audioSourceNode`，直连 AnalyserNode 再输出至扬声器；
- **同源支持**：站内全部介绍视频（`assets/video/*.mp4`）均为本地同源文件，零 CORS 阻断风险；
- **手势激活保活**：用户点击视频播放键（无论是 `video-play-gate` 还是原生控件）本身属于 User Gesture，`actx.resume()` 顺理成章激活，完全符合现代浏览器 Autoplay 策略。

### 2. 视频实时音频分析与 3D 神经网络响应

在视频播放期间（`v.play` 事件触发）：
1. 暂停站点背景音乐，视频成为当前激活的音频源；
2. 启动 `beatLoop()` 帧循环，实时通过 `analyser.getFloatFrequencyData` 提取视频音频中的 Bass（60~250Hz）、Mid（250~4000Hz）和 Treble（4000~12000Hz）能量；
3. 输出带非对称包络与自适应 AGC 增益的 `window.__BEAT`；
4. **3D 神经网络球体（`js/hero-cymatics.js`）实时调制**：
   - 球面声学谐振（Spherical Harmonics 驻波）根据视频旁白与音效高低起伏调制表面点阵波形；
   - 晶格与点阵随音压脉冲（Bass Pulse）产生微米级的张合冲击。

### 3. 视窗外框环境光晕（Ambient Reactive Halo）

在 `beatLoop` 每一帧中检测正在播放的视频，为所在视窗容器 `.cover-box` 添加 `.is-playing-beat` 类，并写入 CSS 自定义变量 `--beat-pulse`：

```css
#products > article.bento-card .cover-box.is-playing-beat {
  will-change: box-shadow, border-color;
  transition: box-shadow 0.08s ease-out, border-color 0.12s ease-out;
}
html:not(.dark) #products > article.bento-card .cover-box.is-playing-beat {
  border-color: rgba(56, 189, 248, calc(0.35 + var(--beat-pulse, 0) * 0.45));
  box-shadow:
    0 12px 32px -4px rgba(37, 99, 235, calc(0.12 + var(--beat-pulse, 0) * 0.25)),
    0 0 calc(16px + var(--beat-pulse, 0) * 24px) rgba(56, 189, 248, calc(0.20 + var(--beat-pulse, 0) * 0.40)),
    inset 0 1px 0 rgba(255, 255, 255, 0.9);
}
.dark #products > article.bento-card .cover-box.is-playing-beat {
  border-color: rgba(56, 189, 248, calc(0.40 + var(--beat-pulse, 0) * 0.50));
  box-shadow:
    0 12px 36px -6px rgba(0, 0, 0, 0.65),
    0 0 calc(18px + var(--beat-pulse, 0) * 32px) rgba(56, 189, 248, calc(0.25 + var(--beat-pulse, 0) * 0.45)),
    inset 0 1px 0 rgba(255, 255, 255, 0.20);
}
```

### 4. 暂停与恢复无缝平滑交接

- 当视频暂停（`pause`）或播放完毕（`ended`）：
  - 立即移除视窗光晕与 `--beat-pulse`；
  - 若播放视频前曾暂停过背景音乐，调用 `resumeMusicIfIdle()` 自动恢复背景音乐，背景音乐的 `play` 事件无缝接管 `beatLoop`；
  - 若用户未开背景音乐，`stopBeat()` 停止循环并将 `window.__BEAT` 平滑置零，3D 背景优雅归于宁静。

## 三、实测运行数据

通过 Playwright 实机测试播放 `FileButler` 介绍视频（`assets/video/filebutler-intro.mp4`）：

```json
Video Playing Audio Beat State: {
  "paused": false,
  "currentTime": 1.422222,
  "beat": {
    "level": 0.2634214652518258,
    "lv": 0.11299070278297282,
    "slow": 0.030081880249621298,
    "rise": 0.00001162995416399299,
    "mid": 0.06732006414496115,
    "treble": 0.0009448433284836632,
    "ctx": "running"
  },
  "boxHasClass": true,
  "boxBeatPulse": "0.226"
}
```

暂停后复位状态：
```json
Paused State: {
  "paused": true,
  "beat": { "level": 0, "lv": 0, "mid": 0, "treble": 0 },
  "boxHasClass": false
}
```

**测试结论**：
1. 视频起播时，`AudioContext` 状态为 `running`，`window.__BEAT` 持续产出高保真音频包络；
2. 视窗容器实时响应 `--beat-pulse`；
3. 视频暂停后，所有状态 100% 干净复位，无内存泄漏与音频挂起。
