## 三、动效特性与技术架构

### 1. 核心视觉元素（100% 还原主站背景）
- **内层微光晶格线框 (Geodesic Cage)**：二十面体线框几何体（Icosahedron），逆向自转与低音微呼吸；
- **斐波那契球面点阵 (Fibonacci Sphere)**：2,800 颗微晶粒子构成的流体网状外壳，带偏微分声学驻波调制；
- **天体双层谐振共鸣环 (Resonance Rings)**：内倾角 65° 大环（320 点）与外宽域 -55° 谐振环（440 点）；
- **伴生流动星尘 (Flank Stardust)**：左右两翼舒展延伸的微光粒子流（550 点）；
- **动态声波扩散环 (Shockwave Ring)**：鼠标点击或脉冲触发时自内向外爆发扩散。

### 2. 内置双模式无缝切换
- **模式 1：3D 拓扑谐振网络球 (Cymatics Mesh Sphere)** —— 与用户截图背景完全一致；
- **模式 2：深层突触神经脉冲网 (Synaptic Neural Graph)** —— 经典 3D 神经元节点互连与前传电脉冲流。

### 3. 控制与交互能力
- **双色温主题**：
  - ☀️ **晨曦明眸（浅色）**：高雅蔚蓝/天青微晶，完全还原用户上传截图效果；
  - 🌙 **极客深空（深色）**：赛博发光电青、自适应加色混合（AdditiveBlending）。
- **指针物理**：鼠标滑过视差倾角跟随；鼠标按住可全方位 3D 自由拖拽旋转；点击任意区域激发能量冲击环。
- **浮动控制台 (HUD)**：
  - 自转速度调节 (0.0x ~ 3.0x)；
  - 驻波律动幅度调节 (0.0x ~ 2.5x)；
  - 粒子尺寸调节 (0.03 ~ 0.18)；
  - 晶格线框、天体环独立开关；
  - 一键手动激发脉冲波。
- **纯享壁纸模式**：支持按键盘 `H` 键或点击右上角眼睛图标一键隐藏所有面板。

### 4. 零依赖环境兼容
采用智能动态导入架构：
```javascript
let THREE;
try {
  THREE = await import('./assets/vendor/three.module.min.js'); // 本地极速离线载入
} catch (e) {
  THREE = await import('https://esm.sh/three@0.160.0');         // 移至别处时自动降级公网 CDN
}
```
无需 `npm install`、无需 Webpack/Vite 打包，**直接双击 HTML 即可在任意现代浏览器中满帧运行**。
