# 产品卡片选择动效与拟真硬件视窗 — 交付记录

## 1. 任务背景与目标
针对用户反馈：“话说我不是说过要给这些卡片选择加入我给的两个HTML文件的动效吗？你怎么没有加入”，对比并提取 `demo-flagship.html`（晨曦流光旗舰版）与 `demo-linear-apple.html`（拟真视窗工作室）的核心动效体系与拟物工艺细节，将它们全面融入主站首页（`index.html`）的 4 款核心工具产品卡片与选择控制交互中：
1. **Linear / Apple 分段选择胶囊栏 (`.product-tabs-bar` & `.product-tab-btn`)**：吸顶浮空磨砂玻璃胶囊，支持 01~04 编号、产品名、分类微标、动态发光圆点与点击平滑居中切换；
2. **macOS 拟真视窗标题栏与交通灯控制 (`.window-header` & `.traffic-lights`)**：红黄绿拟真微立体交通灯、等宽代码风视窗标题与分类徽章，卡片整体呈现 Apple 软件视窗质感；
3. **3D 物理景深微倾斜 (`perspective(1000px) rotateX(...) rotateY(...)`)**：鼠标悬停在卡片上微动时，依据光标偏移产生平滑物理微俯仰倾斜，移出时弹性复位；
4. **双向无缝联动与呼吸脉冲涟漪 (`card-selected`)**：
   - 首屏右侧作品索引（`#home .hero-index`）点击或卡片选择栏点击均能双向同步高亮；
   - 激活目标卡片触发 1.1s 的外扩呼吸能量光环动效（`card-select-pulse-light` / `card-select-pulse-dark`）；
   - 结合 `IntersectionObserver` 监听自然滚动，随页面滚动手势实时切换顶部选择栏高亮项。

## 2. 核心实施细节

### 2.1 HTML 结构增强 (`index.html`)
- 在 `#products` 容器顶部注入 Linear / Apple 规范的分段产品选择栏：
  ```html
  <nav class="product-tabs-bar" aria-label="核心工具切换">
    <button type="button" class="product-tab-btn active" data-product-tab="filebutler">
      <span class="tab-dot"></span><span class="tab-no">01</span><span class="tab-name">FileButler</span><span class="tab-tag">端侧 RAG</span>
    </button>
    <button type="button" class="product-tab-btn" data-product-tab="paian">
      <span class="tab-dot"></span><span class="tab-no">02</span><span class="tab-name">拍案</span><span class="tab-tag">长文模型</span>
    </button>
    <button type="button" class="product-tab-btn" data-product-tab="netops-handbook">
      <span class="tab-dot"></span><span class="tab-no">03</span><span class="tab-name">NetOps</span><span class="tab-tag">离线运维</span>
    </button>
    <button type="button" class="product-tab-btn" data-product-tab="fluxion">
      <span class="tab-dot"></span><span class="tab-no">04</span><span class="tab-name">Fluxion</span><span class="tab-tag">性能套件</span>
    </button>
  </nav>
  ```
- 为 4 张产品卡（FileButler, 拍案, NetOps, Fluxion）顶端统一嵌入 macOS 硬件视窗标题栏：
  ```html
  <header class="window-header">
    <div class="traffic-lights">
      <span class="traffic-dot dot-red"></span>
      <span class="traffic-dot dot-yellow"></span>
      <span class="traffic-dot dot-green"></span>
    </div>
    <span class="window-title">Fluxion_Suite.exe — 游戏性能调优套件 v1.3.0</span>
    <span class="window-badge">性能套件</span>
  </header>
  ```

### 2.2 视觉与动效 CSS 规范 (`css/style.css`)
- **视窗选择栏胶囊**：采用多层投影与高斯模糊（`backdrop-filter: blur(16px)`），浅色模式使用纯白发光与微晶淡蓝边框，深色模式使用深海蓝晶与青色荧光；
- **macOS 交通灯与视窗跨列适配**：
  - 在宽屏桌面端（`min-width: 860px`）通过 `grid-column: 1 / -1; width: 100%;` 跨满左右双栏顶端，卡片 `border-radius: 1.25rem; overflow: hidden;` 实现视窗顶角自然包圆；
  - 交通灯支持悬停微增亮反馈（`filter: brightness(1.08)`）；
- **选中态呼吸脉冲**：浅色模式下发射 `#38bdf8` 与天蓝光晕，深色模式下发射深邃电光青辉与多阶阴影。

### 2.3 交互逻辑与双向同步 (`js/app.js` & `js/bundles/home.js`)
- 升级 `initHeroIndex()` 为产品视窗总控逻辑：
  - 点击选择栏按钮、首屏作品条目或卡片本体，统一触发 `selectProductCard(projectId, smoothScroll)`；
  - 针对桌面端精细鼠标（`pointer: fine` 且非减少动态偏好），计算光标相对于卡片中心的 `(x, y)` 偏移量，应用实时 3D 俯仰微倾斜（`perspective(1000px) rotateX(...) rotateY(...)`），移出鼠标时平滑复位；
  - 注册 `IntersectionObserver`，以视口黄金分割区间实时更新当前所浏览卡片的高亮指示状态。
- 通过 `node scripts/build-bundles.mjs` 重建 `home.js` 脚本包，保证构建一致性检查通过。

## 4. 交付文件清单
1. `index.html`: 注入 `.product-tabs-bar` 分段导航栏与 4 款工具的 `<header class="window-header">` 视窗结构；
2. `css/style.css`: 注入选择栏胶囊、macOS 视窗标题栏、交通灯、双模式对比度与呼吸脉冲动画；
3. `js/app.js`: 升级视窗联动、3D 微倾斜交互与滚动监听；
4. `js/bundles/home.js`: 首页脚本 Bundle 重新构建编译产物；
5. `scripts/test-product-click.mjs`: 自动化动效与响应式截图实测脚本；
6. `docs/screenshots/*.png`: 浅色、深色与移动端高精度实测成果图。
