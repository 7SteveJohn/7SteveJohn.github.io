# 产品卡片单屏化与背景透光重构 · 交付记录

> **交付日期**：2026-11-05  
> **核心目标**：彻底解决产品卡片在标准视口下「单屏放不全需要滚动」与「卡片过于庞大不透明挡住背景 3D 神经网络球体」的问题。

---

## 一、问题背景与根因排查

用户在实际体验过程中反馈了两个关键视觉与交互痛点（附带实测截图对比）：

1. **痛点 1（页面放不全）**：
   - **实测根因**：原产品卡片（`#products > article.bento-card`）在宽屏下采用了纵向单列堆叠布局（`flex-direction: column`），上方大段文本与技术信息（高度约 380px）直接压在下方 16:9 大视窗视频上方（视频限高 520px，实际渲染高度约 500px），加上卡片内外间距，单张卡片总高高达 **940.3px ~ 1050px**。
   - 在 1080p（排除浏览器顶栏与系统任务栏后净可用高度约 820px~900px）或笔记本（1366×768 / 1440×900）屏幕中，卡片高度直接撑爆当前视口，用户无论怎么滚，都无法在同一屏幕中同时看全标题、介绍、下载按钮和视频预览。

2. **痛点 2（挡住背景神经网络图片）**：
   - **实测根因**：对比用户满意的「做工具的几条原则」区域（卡片紧凑、三列横排、70% 半透磨砂玻璃、3D 粒子球居中全景展现），原产品卡片是一个宽 976px、高 940px 的巨大实体矩形，背景不透明度极高（浅色 92%、深色 80%~90%），且视频播放容器填充了 `#000000` 纯黑背景。
   - 导致一旦滚动到产品区，占据屏幕 70% 以上面积的不透明卡片如同一堵厚墙，将视口居中的 3D 神经网络 / Cymatics 粒子球完全遮蔽，屏幕四周仅剩边缘微弱的蓝点碎片。

---

## 二、重构方案与工程实现

### 1. 宽屏左右双栏架构（彻底单屏化）

在桌面与宽屏设备（`@media (min-width: 860px)`）下，将产品大卡重构为左右双列自适应 Grid：
- **左栏（信息与交互中枢）**：
  - 顶层：设备形态/技术栈徽标（如 `端侧 AI 桌面应用 · pywebview / Vue 3 / Ollama`）；
  - 标题：产品大标题（如 `FileButler · 本地文件管家`）；
  - 更新指示胶囊：嵌入式状态条，显示版本号、重点特性与版本历史入口；
  - 简介与难点：极客精炼正文、角色与技术难点阐述；
  - 技术栈标签：紧凑 Chip 标签组；
  - 操作按钮组：网盘下载、GitHub Releases、GitHub 源码图标、了解更多全部在单行紧凑对齐。
- **右栏（硬件感视窗播放器）**：
  - 纯净 16:9 比例硬件视窗，高度严格约束在 ~270px，与左侧文本高度黄金齐平。

```css
@media (min-width: 860px) {
  #products > article.bento-card {
    display: grid;
    grid-template-columns: minmax(0, 1.28fr) minmax(0, 0.92fr);
    align-items: center;
    gap: 1.75rem;
    padding: 2rem 2.25rem !important;
    margin-bottom: 26vh;
  }
  #products > article.bento-card > div:first-child,
  #products > article.bento-card > div:last-child {
    padding: 0 !important;
  }
  #products > article.bento-card .cover-video {
    width: 100%;
    aspect-ratio: 16 / 9;
    max-height: 270px;
    object-fit: cover;
    background: transparent;
  }
}
```

### 2. 液态磨砂玻璃与背景穿透（3D 神经网络全景重现）

借鉴原则卡片的设计，将全站卡片底色全面转向半透高斯模糊质感：
- **浅色模式**：背景调整为 `rgba(255, 255, 255, 0.70)`，搭配 `backdrop-filter: blur(14px) saturate(1.15)`，青蓝粒子与连接网格从卡片后方清晰隐现；
- **深色模式**：背景调整为 `linear-gradient(180deg, rgba(16, 22, 34, 0.58) 0%, rgba(9, 13, 20, 0.70) 100%)`，搭配 `backdrop-filter: blur(14px) saturate(1.25)`，暗夜深空粒子光晕自然透射；
- **播放容器**：移除原本沉闷的纯黑背景 `#020408` 与 `.cover-video { background: #000; }`，改为半透磨砂玻璃边框（深色 `rgba(10, 15, 26, 0.55)`，浅色 `rgba(241, 245, 249, 0.70)`），消除矩形黑洞效应。

### 3. 视口绝对垂直居中与呼吸留白（避免下张卡片偷窥）

- **垂直居中吸附**：Scroll Snap 对齐方式升级为 `scroll-snap-align: center;`，配合动态计算的 `scroll-margin-top: max(64px, calc((100vh - 420px) / 2));`；
- **呼吸空间**：将卡片底部边距设为 `26vh`，保证当任何一张产品卡（如 FileButler、拍案）居中停顿时，上下一张卡片均位于视口之外，上下留出各 >200px 的纯净环形空间，让背景 3D 旋转球体拥有专属舞台；
- **JS 滚轮翻页平滑对齐**：更新 `initProjectSnap()` 与 `selectProductCard()` 的计算逻辑，无论鼠标滚轮还是点击顶部作品索引（`01 FileButler`, `02 拍案`...），均以 `block: 'center'` 精确吸附到视口正中央。

### 4. 版本更新公告精炼胶囊化

原有的桌面版公告由于使用了绝对定位与 `padding-right: 18rem !important;`，挤占了右侧大量空间。现重构成自适应内联胶囊：
- 形式：`● v1.4.3 · 扫描件 OCR / 系统目录排除  全部 11 个版本 →`
- 视觉：微晶胶囊微底色 + 动态电光青脉冲圆点 + 快速直达项目详情弹窗的更新历史锚点。

## 三、实测尺寸与视觉验证数据

在 1440 × 900 标准桌面视口下的 Playwright 自动化精确测量结果：

| 项目 | 重构前卡片总高度 | 重构后卡片总高度 | 视口纵坐标 (Y 轴区间) | 上方净留白 | 下方净留白 | 状态 |
|---|---|---|---|---|---|---|
| **FileButler** | 940.3 px (截断) | **497.5 px** | 201.0 px ~ 698.5 px | 201.0 px | 201.5 px | **完美居中放全** ✅ |
| **拍案 (PaiAn)** | 880.0 px (截断) | **430.7 px** | 228.8 px ~ 659.5 px | 228.8 px | 240.5 px | **完美居中放全** ✅ |
| **NetOps** | 920.0 px (截断) | **477.5 px** | 210.8 px ~ 688.3 px | 210.8 px | 211.7 px | **完美居中放全** ✅ |
| **Fluxion** | 950.0 px (截断) | **492.9 px** | 203.4 px ~ 696.3 px | 203.4 px | 203.7 px | **完美居中放全** ✅ |

**实测结论**：
1. 四款产品单卡高度全量控制在 **430px ~ 497px** 之间，相比此前下降了 **47% ~ 54%**；
2. 在 900px 视口中，上下各有超过 **200px** 的宽裕留白，3D 神经网络球体完整显露且居中对称；
3. 一屏之内同时完整清晰呈现：产品徽标、标题、版本指示胶囊、功能简介、技术标签、4 个操作按钮与 16:9 视窗播放器，用户零需滚动即可纵览全貌。
