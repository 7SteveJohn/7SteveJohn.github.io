## 3. 技术优化与改动点

1. **CSS Grid 黄金密排布局**：
   - 采用 3 列网格 + `grid-auto-flow: dense` 算法；
   - 第 1 行由 `2 列宽横幅（星锑洞悉二）` + `1 列标准卡片（星锑&APPLe）` 填满；
   - 第 2-3 行由 3 张 `tall 跨双行竖图（蕾姆、六花、碧翠丝）` 并列填满；
   - 第 4 行由 3 张标准卡片整齐收尾；整面照片墙实现 0 缝隙、错落有致的视觉韵律。
2. **WebP 高清极速加载**：
   - 所有图片均压制为现代高质量 WebP 格式（平均体积 160KB~350KB），在 Retian 级清晰度下实现瞬时秒开。
3. **灯箱全景与元数据联动**：
   - 全屏灯箱支持单张大图完整展示（`object-fit: contain`），键盘 `←` `→` 平滑切图与 `Esc` 退出。
4. **备份安全**：
   - 原项目封面数据以 `window.GALLERY_PROJECTS_BACKUP` 在 `js/gallery.js` 中保留备份，随时可按需唤醒或增加 Tab 筛选。
