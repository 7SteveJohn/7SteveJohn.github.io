# 音乐律动与 3D 声学共鸣修复交付记录

## 1. 问题根因分析 (Root Cause Analysis)

在先前版本中，用户反馈在播放背景音乐或介绍视频时「音乐律动怎么又没了」。经实测排查，根本原因来自以下多层链条的衰减与断层：

1. **`BeatDetector.js` 击拍门限过高过滤掉 95% 鼓点**：
   - 原代码写死 `this.justBeat = prev < 0.5 && this.pulse >= 0.5;`。
   - 在真实音乐播放时（如站点默认曲目），`window.__BEAT.level` 的瞬态峰值通常在 `0.20 ~ 0.45` 之间。经过攻击系数平滑后，`this.pulse` 极少能够越过 `0.5` 阈值，导致 `justBeat` 几乎永不为 true，`onBeat()` 回调从未被触发，所有场景的单发重音事件处于停摆状态。

2. **`CymaticsField.js` 完全忽视离散鼓点包络 `beatEnv` / `window.__BEAT.level`**：
   - 原代码仅从 `audio.bass` 读取低频能量：`const bass = (audio && audio.bass ? audio.bass : 0) + this.kickEnergy * 0.5;`
   - `audio.bass` 经过 3s 衰减式 AGC 归一化后，稳态电平仅为 `0.02 ~ 0.05`。
   - 原代码 `cageScale = 1.0 + bass * 0.14`，形变幅度仅为 `0.05 * 0.14 = 0.007`（**仅 0.7% 的微弱涨落**）。
   - 斐波那契球面点阵驻波幅值 `rGain = 1.0 + wave * (0.12 + bass * 0.32)`，低音调制量仅为 `0.016`（**仅 1.6% 波动**）。肉眼完全无法将其与闲时正弦呼吸区分开，观感如同一尊静止石雕。

3. **浅色模式下声学激波环因加色混合 (AdditiveBlending) 隐形**：
   - `this.ringMat` 初始写死 `blending: THREE.AdditiveBlending` 与青色 `0x38bdf8`。
   - 浅色模式背景色为近纯白 `#f8fafc` (`rgb(248, 250, 252)`)。在接近 255 的底色上叠加青色光，RGB 各通道直接溢出钳制至 255，结果为 `#ffffff`。白色激波环在白昼底色下 100% 视觉隐形。

## 2. 核心修复方案与实现细节

### 2.1 `BeatDetector.js` 灵敏度与上升沿重构
- **响应门限下调**：`prev < 0.20 && this.pulse >= 0.20`，完美捕捉真实母带的每次重鼓与底鼓切入。
- **瞬态攻击提速**：起音响应系数提升至 `0.80`，释放系数设为 `0.12`，让击拍脉冲在 1 帧内迅速打满，绝不被平滑算法削峰。
- **220ms 不应期防抖**：避免单次波形上升沿产生多次误触，严格保证音乐乐句的清晰鼓点节奏。

### 2.2 `AudioManager.js` 信号链增强
- 在站点歌单或视频驱动 `window.__BEAT` 时，将瞬态重拍能量注入低音域：
  `b = Math.max(B.lv || 0, (B.level || 0) * 0.85);`
  让下游所有依赖 `bass` 的连续材质与 Shader 都能在重鼓瞬间感受到能量爆发。

### 2.3 `main3d.js` 统一传递动态 Pulse
- 在渲染主循环中将 `beat.update()` 产出的连续归一化 `pulse` 作为第 5 参数传入 `currentField.update(sceneT, a, interaction, dtMs, pulse)` 与 `currentField.updateEngine()`。
- `beat.justBeat` 触发时，按乐句重音传递清晰的打击强度（普拍 0.75，第 8 拍乐句重音 1.0）。

### 2.4 `CymaticsField.js` 声学谐振与激波环全维重塑
1. **多重音频特征提取**：
   综合提取 `pulse`、`audio.beatEnv`、`window.__BEAT.level` 与交互 `kickEnergy`，得到肉眼可见的物理击拍响应 `beatPulse`。
2. **多面体网格笼动态伸缩 (+25%)**：
   `cageScale = 1.0 + beatPulse * 0.25 + bass * 0.10 + Math.sin(sceneT * 1.5) * 0.02;`
   每当鼓点响起，外层二十面体线框犹如心脏般向外弹性扩张 25%。
3. **斐波那契点云声学驻波与外扩**：
   `rGain = 1.0 + wave * (0.12 + beatPulse * 0.36 + bass * 0.16) + (beatPulse * 0.12 + bass * 0.06);`
   整个点云球不仅整体向外膨胀 12%，球面上的克拉尼谐振驻波幅度更从 0.12 猛增至近 0.50，呈现清晰震撼的流体震荡感。
4. **两翼流动星尘向外爆发起伏**：
   `fArr[i * 3 + 1] = by + Math.sin(bx * 0.5 + sceneT * 0.8) * 0.22 + beatPulse * 0.35 + bass * 0.12;`
   `fArr[i * 3] = bx + Math.cos(by * 0.4 + sceneT * 0.5) * 0.08 + Math.sign(bx) * beatPulse * 0.15;`
5. **强拍自动激发生波环与浅色模式修复**：
   - 当 `beatPulse > 0.38 && this.shockProgress === 0` 时，自动激发扩散波环。
   - 明暗材质自适应：深色模式使用 `0x38bdf8` + `AdditiveBlending`；浅色模式自动切换为深天蓝 `0x0284c7` + `NormalBlending`，并在白色底色上保持 `0.55` 鲜明不透明度，彻底解决白底隐形缺陷。
6. **全材质击拍辉光联动**：
   点阵、外笼、双层轨道环以及星尘材质的不透明度均附加 `+ beatPulse * 0.15` 的瞬态辉光。

### 2.5 `NeuralField.js` 等场景全面协同
- `NeuralField.js` 中的 `updateEngine` 同样接收 `pulse`，让输入层向隐藏层传递的脉冲波、连边底亮与节点高频闪烁与音乐节拍完全对齐。

## 3. 验证与实测结果 (Verification Results)

我们通过 Headless Chrome 自动化验收套件进行了全流程实测（脚本：`scripts/verify-music-beat-visual.mjs` 与 `scripts/verify-video-music-mutex.mjs`）：

1. **背景音乐播放实测**：
   - 音乐正常起播，`window.__BEAT` 稳定产出节拍包络。
   - `beatLevel` 随鼓点动态冲高至 `0.602`。
   - 3D 网格笼与驻波发生强劲弹性起伏与声学环扩散。
2. **介绍视频播放实测**：
   - 点击播放视频时，背景音乐无缝暂停。
   - 视频音频流实时接入 Web Audio 分析器，`beatLevel` 冲高至 `0.655`，视频外框光晕 `--beat-pulse` 随之实时外扩至 `0.657`。
   - 背景 3D 场景同步跟随视频原声音频进行声学共鸣。
3. **互斥与滚动恢复实测**：
   - 页面向下滑出视口后，视频毫秒级精准暂停，音乐自动恢复，律动平滑过渡，回归测试 100% 通过。
4. **静态资源构建与缓存对齐**：
   - 执行 `node scripts/build-bundles.mjs`，所有 bundle 重新构建并通过一致性校验。
   - Service Worker 缓存版本升级至 `sevenjohn-v232`。
