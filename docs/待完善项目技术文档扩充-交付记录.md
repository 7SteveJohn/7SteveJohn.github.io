## 二、关键技术内容与实现要点

### 1. 提示词优化器（离线版规则引擎）
- **痛点反思**：反对“微调几十个字提示词必须先向云端请求一次大模型”的惯性，将提示词工程缺陷定性为静态检查（Linter）与骨架缺失问题。
- **四大处理阶段**：
  1. 文本特征探测（中英文词边界识别、MATTR 词汇变化度）；
  2. 10 项结构完整度打分（基础 8 项 + 条件触发 2 项，输出逐项扣分明细）；
  3. 机械矛盾诊断（6 组互斥要求冲突、素材缺失指代、声明一致性冲突、不可见字符/全角数字清洗）；
  4. 结构化重组与两级修复（安全级直接应用，确认级提供 Diff 预览并支持行内豁免 `（po-ignore：...）`）。
- **工程纪律（定标否决记录）**：详细记录了为什么通过定量测试否决了微编辑重复检测（nearDup，LCSR margin −0.052）与“指令空转”提示（抽象词密度分布重叠）。

### 2. 2D 像素叙事游戏开发手记（迁移至 RPG Maker MZ）
- **选型与架构决策**：
  - 从 Godot 4 迁移至 RPG Maker MZ，卸下通用引擎在 2D 瓦片网格移动、对话调度与平滑排版上的重复造轮子负担，聚焦叙事表现力。
  - 通过 MCP 与外部脚本直接读写底层 JSON 与事件状态，升级为现代代码驱动管线。
- **核心自研模块**：
  - **定制全屏阅读器**：打字机渐显、长按动态加速、插画透明度约束（$\le 30\%$）、生命周期隔离与双保机制（游戏存档 + `localStorage`）。
  - **空间叙事与事件状态机**：章节阅读完成驱动全局开关，唤醒地图物体的次级调查页，从日常陈设变为承载回忆与心理回响的交互反馈。
  - **3 帧循环钟摆步态动力学**：中立过脚帧、前迈与后蹬提踵推地、对侧曲肘自然摆臂代偿与 1px 触地重力下沉（Bobbing）；道具行走图严格遵守 `!$prop_*.png` 48×48 网格对齐规范。
  - **瓦片自适应脚步声**：9 套地表材质脚步声根据玩家脚下 TileID 实时分发并叠加音高微抖动；环境 BGS 原生无缝循环。
  - **现代轻透 UI**：曜石圆角胶囊菜单、磨砂琉璃卡片与肖像底部渐变羽化。
- **当前研发进度状态**：
  - 文本流水线（83 章主线/结局/彩蛋转码完成度 100%）；
  - 阅读引擎（生命周期防护与图鉴点播 100%）；
  - 8 大核心场景地图（事件接线与生活化校准 100%，门界与通行性测试 100% PASS）；
  - 自动化回归套件全绿通过。

### 3. 本地视频阅读工作流（基于 `D:\ffmpeg工作流`）
- **传统算法与大模型分工**：
  - 镜头切分坚决交给传统 OpenCV / PySceneDetect（定标实测：Qwen2-VL-8B 镜头切分 F1 仅 22，而 PySceneDetect 达 69）；
  - 动态分位数自适应定标（`cut_thr = max(p95 * 1.2, p50 * 3)`），在镜头边界 ±1s 范围内加密至 0.25s 采样；
  - faster-whisper 离线转写（动态挂载 cuBLAS DLL，GPU 耗时 6.3s vs CPU 29.2s）；空音频/纯音乐素材自动嗅探熔断；
  - 本地 Ollama 驱动 Qwen2.5-VL:7B 读帧（单批次上限 3 张图防 HTTP 400）；
  - 文本侧 bge-m3 稠密向量索引 + 画面侧 ONNX 量化 CLIP 跨模态向量索引，避免重复全量推理；
  - 交付三件套：Markdown 纪要 + Docx 文字稿 + 关键帧 PDF 画册。

### 4. 《渊狱行者》（纯前端 60KB 矢量 Roguelike 引擎）
- **零依赖极限设计**：
  - 零外部图片依赖（0 个 PNG/JPG）：13 种生物与全部地牢瓦片由 Canvas 2D 路径与三角函数动态绘制；
  - 零外部音频依赖（0 个 MP3/WAV/OGG）：16 种交互音效由 WebAudio API 振荡器与白噪音实时频率合成；
  - 纯原生单页（~60KB，双击 `index.html` 即玩）。
- **地牢系统**：
  - Mulberry32 确定性种子伪随机数发生器；
  - 房间挖掘与走廊连接算法，楼梯锚定在最远端分支房间；
  - BFS 怪物 AI 追踪与寻路；
  - Bresenham 视线投射（FOV）与动态战争迷雾衰减；
  - 10 层深渊数值递增，装备与三选一卡牌构筑，死亡魂晶沉淀与祭坛永久强化。
