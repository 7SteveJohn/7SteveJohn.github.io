## 二、站点架构

### 技术栈
- 静态页，无框架。Tailwind 3.4.17 预编译产物 `assets/vendor/tailwind.css`（改了类名要重建，命令见 README）
- marked / highlight.js / DOMPurify / lucide 全自托管于 `assets/vendor/`，**全站零外链脚本**
- Service Worker（`sw.js`）全面 stale-while-revalidate；`CACHE = 'sevenjohn-vNNN'`
- 首屏脚本合并为 6 个 bundle（`js/bundles/`），由 `scripts/build-bundles.mjs` 生成

### 改东西的固定流程
| 改什么 | 必须做 |
|---|---|
| `js/` 下任何源文件 | `node scripts/build-bundles.mjs` 重建（`--check` 验证） |
| `posts/*.md` | `node scripts/build-articles.mjs`（顺带重生成 rss/sitemap） |
| 站名/导航/社交 | 只改 `js/site-config.js`（单一来源） |
| 产品卡 | `js/projects.js` + `node scripts/gen-card-copy.js` |

### 验证套件（改完必跑）
```bash
python -m http.server 8327 --directory D:/HTML   # 或 node scripts/dev-server.js（8328）
node scripts/smoke-home.mjs        # 17 断言：首页结构/卡片/深链
node scripts/stability-check.mjs   # 9 断言：滚动/弹窗/深链/搜索/手机/离线
node scripts/swr-check.mjs         # 6 断言：SW 缓存策略（需 dev-server）
node scripts/smoke-media.mjs       # 18 断言：音乐/视频/离线播放
```
全部要求 localhost（**SW 注册守卫只认 `localhost`，传 127.0.0.1 会静默不注册**，"断网可读"断言必挂）。

### 版本号纪律（重要）
`sw.js` 的 `CACHE` 版本号**只在改 CORE 清单/缓存结构时 +1**；普通内容变更靠 SWR 自动对齐，**不 bump**。2026-10-26 曾一天 bump 10 次（v147→v157），导致用户每次刷新都全量重装 CORE——这就是"加载慢"的体感来源，勿重蹈。

## 四、看板娘「7steve」（核心资产，2026-10-17 起）

### 4.1 文件链路
```
D:\live2d\7steve.jpg（概念原画）
  → D:\live2d\7steve_clean_master.psd（687×1024 分层 master，37 层）
  → psd2live 管线烘焙 → moc3 + 4096 贴图
  → D:\HTML\assets\vendor\live2d\model\7steve\（站点部署）
驱动：js/live2d.js（闸门/预热/启动/语义交互）
运行时：assets/vendor/live2d/（live2d-widgets@1.0.1 fork，GPL-3.0，改过一版）
```

### 4.2 闸门与形态（js/live2d.js）
| 条件 | 结果 |
|---|---|
| `sj.live2d=off`（右上角已无叉号；关闭通道=设置面板开关） | 不出现 |
| 手机 / 视口 <1024 | 不出现 |
| 系统减少动效（未显式开启） | **静态立绘**（`7steve-static.webp`，点击可升级动态版） |
| 省流量 / 无 WebGL / 弱机档 | 静态立绘 |
| `sj.live2d=on`（显式开启）或正常环境 | **动态 Live2D** |
| `*.pages.dev` 域名 | 永不加载（简历档） |

### 4.3 加载性能（已深度优化，别退化）
- **预热**：load 后 idle 以 low priority 预取全套模型资产进 SW 缓存；`fire()` 等预热收敛（8s 兜底）再启动——**运行时请求必须命中缓存**，否则冷启动双下载 ~700KB
- **即时弱机自检**：WebGL + 软渲染签名 + 核心数，毫秒级；不等壁纸引擎的档位判定（它要实测 ~5s 帧率）
- **显形条件**：`waifu-active` **且** `__live2d_app._state >= 22`（CompleteSetup=贴图全部上 GPU）。只等 waifu-active 会有 5-10s 隐形窗口（气泡在、人空白）
- 实测：热访问 619ms 就绪，冷访问 1.4s（localhost）；生产冷 ~6s（网络瓶颈，~1.2MB 真实传输）

### 4.4 交互与动作（全在数据层，别动 vendor 压缩码）
- 动作组随机轮播：Idle×6（自研 3 + Shizuku 移植 3）、FlickHead×5、TapBody×5、Shake×3
- 语义表情：`live2d:taphead/tapbody/tapcat/taptablet` 事件 → `__live2d_app.setExpression(下标)`（0 smile 1 shy 2 focus 3 wink 4 surprised）；连戳身体 3 次（6s 窗）→ 瞪眼 + Shake 抗议
- 物理链 4 条：前后发 + 果冻眼 + **BodyFollow**（头转→身体惯性跟随，自加）
- `window.__live2d_model` / `__live2d_app` 是 vendor 暴露的调试探针

### 4.5 模型构造（改贴图/绑定前必读）
- 模型 canvas 687×1024 与原画 1:1；图集三张 4096（站点用 webp q92）
- **图集手术规矩**：改图集先改 PNG（`D:\live2d\export_turnfix\*.png` 为无损基准），**webp 只编码一次**——反复 q90 重编会累积代损把脸糊掉（踩过）
- **图集岛位置与艺术坐标无关**（打包器决定），定位靠模板匹配（`TM_SQDIFF_NORMED` 有界 0-1；**TM_CCORR_NORMED 带掩码分数会溢出 >1，禁用**——曾误删马尾块）
- 外围漂浮物件（猫/面板/爱心）已从贴图抹除（半身窗不再切碎它们）；角色本体和手中全息屏保留
- ParamAngleX=±45 / Y=±30 的关键形曾全部损坏（自动绑定生成折叠几何），已通过 MCP 复制中心键几何修复（270+234 键）。**若重新烘焙模型，这些修复会丢失，需重放**

### 4.6 半身像构图（CSS 级，改大小动这里）
- `css/style.css`：`#waifu` 340×340 overflow:hidden 裁切窗 + `#live2d` 680×680 !important 2x 渲染（运行时无视 model3.json 的 Layout 缩放，**画布尺寸才是旋钮**；backing 随 CSS 尺寸重算）
- 静态立绘 = 同构图裁切，`assets/vendor/live2d/7steve-static.webp`

## 五、Live2D 制作管线（D:\live2d）

- **PSD2Live MCP**：`python D:\live2d\psd2live_mcp_bridge.py`（stdio JSON-RPC，自动拉起 headless 引擎 3.5.1 @127.0.0.1:23871）。通用驱动：`scripts/live2d/psd2live-mcp-driver.py`
  - 参数包装：顶层 `{op?, request:{...}}`；必带 `request_id/project_id/state`（state 从 workspace_inspect 拿）
  - 关键操作：`keyform_apply`（copy/seed/set）、`rig_deform`（translate/scale/rotate）、`object_edit_appearance`（⚠️ visibility 实测不生效）、`project export_model`
  - 单批 changes ≤128；历史分支用 `history list/checkout` 回滚
- **Cubism Editor 手绑**是剩余上限（转头 3/4 透视）的唯一路径：`7steve_perfect_master.psd`（37 层）+ `Live2D看板娘素材清单.md`（含验收红线与约稿需求书）均已就绪
- 动作转换：`scripts/live2d/convert-shizuku-motions.py`（.mtn → .motion3，剥除 7steve 没有的参数）
- meta 计数修正：`scripts/live2d/motion-meta-fix.py`（TotalSegmentCount 必须按段类型遍历：贝塞尔 7 值）

## 六、遗留事项（按优先级）

1. **转头 3/4 透视**（质变级）：Cubism Editor PRO 手绑或约稿，资产全齐
2. **大幅转向（±45°）后发覆盖不足**：露窄缝，美术层问题，需画师加宽后发
3. **engine 渲染仍显示物件**：引擎内存贴图与站点文件不同步——测观感一律看站点/浏览器，别看 engine 渲染
4. `js/app.js` 两处 innerHTML 拼接未转义（Mimosa 标记，第一方数据低风险，用户未拍板）
5. Temp/ 目录易被系统清空：本轮关键工具已抢救进 `scripts/live2d/`，其余一次性脚本（erase-props 等）随用随写
6. 简历域名升级路径：自有域名绑 CF Pages（~¥60/年）或国内备案，站子侧改六个常量即可切换
