## 一、 核心设计目标与守恒契约

1. **100% 保留并增强现有 3D 动效与音乐律动**：

## 二、 视觉重塑与新增微交互细节清单

### 1. 吸顶导航栏与微距 HUD 遥测角标
- **几何品牌徽标 + 硬件键帽 `⌘K` 搜索钮**：修复原顶栏搜索文字与快捷键隐藏缺失问题，改为带立体键帽阴影的命令胶囊（窄屏自动收拢为精巧图标）。
- **全页阅读滚动进度光丝（`#page-scroll-bar`）**：嵌于吸顶导航底边 `1.5px` 轨道内，经 `requestAnimationFrame` 驱动纯合成器 `scaleX(...)` 变换，零重排回流。
- **双侧交互式 HUD 角标（`.cosmos-hud`）**：
  - 左上角标随滚动实时同步当前章节坐标（`01 · OVERVIEW` → `02 · TOOLS` → `03 · PRINCIPLES` → `04 · PROFILE` → `05 · NOTES`）；
  - 右上角标内置声学谐振脉冲指示灯（随重拍实时缩放发光）与 **`FIELD` 3D 物理场一键轮播开关**（支持在首页实时切换 `声学谐振 / 神经脉冲 / 极光流体 / 克拉尼场`）。

### 2. Hero 首屏舞台重构（零重叠 + 实时四频段频谱 + 五联作品矩阵）
- **呼吸状态眉标胶囊与可交互更新遥测条**：眉标独立成半透光学胶囊；`#hero-updated`（「最近更新 … →」）升级为可点击遥测胶囊，点击平滑定位至最新更新的工具卡片。
- **实时四频段频谱伴读胶囊（`#cosmos-enter`）**：播放音乐时音符图标自动切换为由 WebAudio 低/中/高/节拍包络实时驱动的四根频谱柱（`--eq-1..4`），并动态滚动显示当前播放曲名（`律动 · <曲名>`）。
- **五联旗舰作品命令矩阵（`.hero-index`）**：将原单薄文字条升级为五列建筑感网格坞，完整呈现每款工具的 `序号 + 版本胶囊 + 名称 + 一句话核心定位`，并彻底修正原底部 `#page-next` 下翻圆钮压住作品条的重叠问题。
- **色彩体系归一**：清理暗色模式下残余的橄榄黄绿（`#c2d96b`）局部高亮，全站统一收敛至与 3D 谐振球同源的冰晶青蓝（`#38bdf8` / `#0284c7`）。

### 3. 五大产品专栏、工程原则、创作者档案与文章区

## 三、 性能优化与冗余清理明细

1. **WebGL 3D 谐振场帧循环提速（三角函数开销降低 ~1,200 倍）**：
   - `js/cosmos/scene/CymaticsField.js`：预计算 `2,800` 颗球面点与 `600` 颗两翼星尘的空间常量正余弦表，利用和差化积恒等式将每帧 `9,600` 次超越函数调用压缩至 `8` 次标量 `sin/cos` + 乘加运算（数学输出恒等零误差）；为动态顶点缓冲声明 `THREE.DynamicDrawUsage`；增加 `_lastDark` 守卫，避免每帧重复触发 6 组材质的混合模式脏标记。
2. **3D 非默认场景按需动态加载（首屏省去 5 个模块请求）**：
   - `js/cosmos/main3d.js`：仅首屏静态引入默认 `CymaticsField`，其余 5 套备选场景（`Neural` / `Aurora` / `Chladni` / `Monolith` / `Isolines`）改为切换时按需 `import()` 异步加载，并经 `MutationObserver` 缓存主题状态。
3. **音频节拍循环零 DOM 查询改造**：
   - `js/player.js`：缓存产品视频节点及容器引用，彻底移除 `beatLoop()` 内每秒 `60~120` 次的 `document.querySelectorAll('#products video')` 遍历。
4. **HTML / CSS / Service Worker 瘦身**：
   - 移除 `index.html` 中历史遗留的 `110+` 处无用可视化编辑器属性 `data-page-node-id`；
   - 移除 `css/style.css` 中三段已废弃的历史原型样式块（旧版 Hero Bento 沙盘、旧版 `#waifu` 挂件覆盖层、旧版分栏 3D 视口）；
   - 更新 `sw.js`（`sevenjohn-v295`），从 `CORE` 预缓存列表剔除 7 个废弃原型页与旧脚本，补齐 `cards.html`、`css/cards.css`、`js/cards.js` 与 `cover-stacky.webp`。
5. **仓库与磁盘冗余文件精准清理（共清理 `5,686` 个冗余文件，释放 `1,015.04 MB`）**：
   - 清理本地临时帧与测试快照目录：`Temp/*`（保留空目录供冒烟脚本写入，`971.15 MB`）、`gui-test-screenshots/`（`17.96 MB`）、`holo-card/` 与 `holo-preview.png`（`12.92 MB`）、`out/`（`0.46 MB`）；
