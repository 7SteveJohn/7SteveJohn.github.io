## 2. 详细技术改造清单

### 2.1 标杆大作《Cyberpunk 2077》与 DLSS 3.7+ 真实工作台对接
- **修改文件**：`Temp/render_fluxion_apple.py`
- 将选定窗口 `WIN_LIB_SEL` 绑定为原生渲染的 `real_dark_p2_cp2077.png`。
- 界面精准呈现：
  * **主标题与运行态**：`Cyberpunk 2077` · `Steam · DLSS 3.7+ 代理已启用 · 帧生成就绪`。
  * **适配方案与底层注入**：`自动 · DLSS 帧生成 (RTX 5090 伪装注入)` · `当前: DLSS 多帧生成已就绪 (120 FPS → 280 FPS)` · `① 代理已挂载: nvngx_dlssg.dll | 伪装入口: D3D12 / DXGI`。
  * **实测硬核数据**：`实测帧率: 120 FPS → 280 FPS (延迟 41.7ms → 17.8ms)`。

### 2.2 仪表盘稳帧与赛车引擎声浪（High-Octane Rev Sweep）
- **稳帧代码优化**：
  ```python
  if t < 1.5:
      cur_fps = 120.0
  elif t < 7.0:
      acc_prog = ease_in_out(clamp01((t - 1.5) / 5.5))
      cur_fps = 120.0 + (280.0 - 120.0) * acc_prog
  else:
      cur_fps = 280.0 # 消除波动，绝对锁定满帧
  ```
- **音频母带合成**（`Temp/generate_all_60s_audio.py`）：
  * 合成 `rev_sweep_turbo(dur=5.5)`，基频从 120 Hz 随非线性加速度曲线指数攀升至 280 Hz，叠加 2 次、3 次、4 次谐波与软饱和破音（`np.tanh`），混合 1000Hz~3400Hz 动态增压进气风噪。
  * 在 master timeline `21.5s` 精准切入声浪，在 `25.5s` 叠入次低音前兆，在 `27.0s` 满帧锁定的刹那以 `gain=0.85` 引爆结晶水晶钟与 Sub-Bass 冲击，视听提速感强烈且与 Apple Minimal Tech 整体节奏浑然一体。

### 2.3 根治 Consolas 字体缺字方框
- 对 `Temp/render_fluxion_apple.py` 中的文字层进行排查，彻底剔除中文文本使用 `mono=True` 的致命错误：
  * 行 705：`rr = text_img(rres, font(30, "Bold"), rcol)`（修复制式「单屏自锁保护」）
  * 行 629：`p_n = text_img(p_name, font(22, "Bold"), INK)`（修复「GPU 硬件加速调度 (HAGS)」等中文系统参数）
- 自动化裁剪与像素分析验证：字形完好，无一处退化方框。
