## 一、 项目背景与交付概览

本工程旨在为个人技术与产品博客「**楠屿札记**」（`7stevejohn.github.io`）打造专属定制的 Live2D 看板娘体系，将通用示例模型平滑过渡至具有高度品牌辨识度的官方看板娘「7steve」。

基于站长提供的概念原设图 `7steve.jpg`，结合站点右下角 `300×300` 视口、深色玻璃极客风视觉语言及高性能/本地优先（Local-First）原则，本次完善工作涵盖了**全套素材清单制定**、**32 级图层与参数绑定规范**、**一键约稿需求书**、**多规格视觉资产抠图提取**、以及**站点底层运行时双模型平滑接入与极客台词库建设**。

## 二、 核心规格决议（设计与技术 Tradeoff）

| 决议项 | 最终方案 | 决策依据与权衡 (Tradeoff) |
|---|---|---|
| **构图** | **半身像**（头顶发光猫耳至卫衣下摆/腰部，含双手托全息屏） | 站点右下角固定为 `300×300` 容器。若用全身像，缩小后头部仅占 35–45px，黑框眼镜、虹膜细节与眨眼完全糊掉；采用半身像，头部尺寸提升至 ~140px，兼备面部表情、发丝摆动、发光猫耳与全息浮动界面的黄金视觉冲击。 |
| **画风与比例** | **正常日系二次元比例**（约 1:5.5 头身比，继承原画） | 楠屿札记为本地 AI 工具与技术手记站，正常比例的科技少女比低幼 Q 版更贴合极客硬核气质。 |
| **交互范围** | **全链路 5 重互动**（呼吸摆动 + 视线追踪 + 点击全息屏 + 扶眼镜 + 摸头猫耳抖动） | 兼顾互动丰富度与 WebGL 渲染开销，待机物理链限制在 5 组以内，避免低端机掉帧。 |
| **模型格式** | **Cubism 4/5 格式为主，向下兼容 Cubism 2** | 当前主流 Live2D 绑定师均采用 Cubism Editor 4/5 导出 `.model3.json` + `.moc3`；站点已打通 Cubism 5 与 Cubism 2 双格式共存链路。 |

## 三、 32 级精准图层与绑定参数规范

全部分层均遵循 2048×2048 透明背景标准，彻底消除智能对象并栅格化图层样式：

1. **漂浮外设层**：`pet_cyber_cat`（赛博猫小七）、`prop_holo_screens`（左右悬浮代码与图表）、`prop_pixel_icons`（像素爱心与 7 字小云）。
2. **耳机与发饰**：`acc_cat_ear_L/R`（猫耳）、`acc_cat_ear_glow_L/R`（`#00D2FF` 发光图层）、`acc_headphone_band`、`acc_headphone_cup_L/R`。
3. **眼镜与配饰**：`acc_glasses_frame`（黑框眼镜）、`acc_glasses_lens_hi`（半透明镜片反光）。
4. **面部五官（微动核心）**：`hair_front_bangs_L/M/R`（刘海拆 3 片）、`eyebrow_L/R`、`eyelash_up_L/R`、`eyelash_down_L/R`、`iris_L/R`（虹膜）、`eye_white_L/R`（眼白遮罩）、`eye_hi_L/R`、`face_skin`、`cheek_blush`、`mouth_up/low/inside`。
5. **灰蓝双马尾**：`hair_twintail_L_01/02`、`hair_twintail_R_01/02`（每侧拆 2 段，做两级串联物理摆动）。
6. **卫衣与躯干**：`hoodie_hood`、`hoodie_collar`、`hoodie_string_L/R`（左右抽绳独立晃动）、`body_hoodie`（含 "7steve" 胸标）、`badge_html5`、`badge_js`。
7. **手持全息屏**：`arm_L_hand`（点击食指）、`arm_R_hand`（托屏手势）、`prop_holo_tablet`（"Hello World! JS" 半透明屏）。
8. **防穿帮 5 大红线**：镜框下眼球眼皮 100% 补全；全息屏后衣服褶皱与文字补全；双马尾甩动时后脑勺与兜帽阴影补全；张嘴时牙齿舌头补全；边缘保留 8–12px 拓展余量。

## 五、 站点底层工程改造与无缝对接机制

在博客主站 `D:\HTML` 中，已实施下列工程优化：

1. **智能模型探测与平滑降级（`js/live2d.js`）**：
   - 配置 `MODEL_7STEVE` 与 `MODEL_SHIZUKU` 双探针。
   - 优先探测 `model/7steve/` 是否就绪；若尚未编译放置，静默回退至 `model/shizuku/`，实现**零报错、零白屏、全天候稳定展示**。
   - 一旦将 7steve 模型解压至指定目录，站点自动热切换，无需更改任何 JS 代码。
2. **极客与产品专属台词库（`assets/vendor/live2d/waifu-tips.json`）**：
   - 新增 7steve 专属模型注册项与问候语。
   - 新增针对站内 5 大重点 AI 工具的智能悬停与点击触发台词：
     - **FileButler**：本地文件标签与即时秒搜提示。
     - **拍案**：视频口播拆解与结构化手记提示。
     - **NetOps**：离线应急运维手册与命令秒查提示。
     - **Fluxion**：极简无依赖代码工作流提示。
     - **GameBoost / DLSSG**：显卡帧率榨干与插帧黑科技手记提示。
   - 新增代码块（`pre` / `code`）悬停代码分析彩蛋、GitHub 开源仓库引导。
3. **Cubism 4/5 运行时组件引入（`scripts/vendor-live2d.js`）**：
   - 提取并就绪 `chunk/index2.js`（Cubism 5 模型运行时），打通现代 `.moc3` 模型的动态加载通路。
4. **性能与离线策略保持**：
   - 坚持不进入 `sw.js` 的 `CORE` 预缓存列表，首次交互或延迟 3.5s 启动，绝不与首屏关键 CSS/JS 抢占带宽。
   - 遵循深色玻璃气泡外观与移动端彻底隐藏规则。
