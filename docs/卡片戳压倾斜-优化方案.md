# 物理翘板卡片真 3D 戳压倾斜交互升级方案与交付记录

## 1. 核心需求对齐

用户精准指出：“**我要的就是它是一张卡片，我戳这边，它会往这边倾斜，是这种意思。你怎么就一直没有做出来呢？你光给出了光晕特效**”。

### 此前未能生效的底层根因：
1. **CSS 特异性压制**：在 `css/style.css` 中，`.js .reveal.is-visible` 带有 `transform: none`。由于它的类选择器特异性高于普通 `.bento-card:hover`，当卡片滚动进入视口被打上 `is-visible` 后，样式表强行将 `transform` 锁死为 `none`，导致肉眼看不出卡片的 3D 旋转；
2. **光晕抢戏**：此前在卡片上方叠加了高亮的径向渐变跟随层（`radial-gradient`），视觉重心全被光晕吸走，而几何倾斜被稀释；
3. **缺乏“按压深陷”状态**：此前只监听了 `mousemove`，没有处理 `mousedown` 与 `touchstart`，导致用户手指或鼠标“戳下去”时完全没有按压下陷的物理反馈。

---

## 2. 真实物理翘板解决方案（v240）

### (1) 解除 CSS 压制
在 `css/style.css` 中将规则调整为：
```css
.js .reveal.is-visible {
  opacity: 1;
}
.js .reveal.is-visible:not(.bento-card):not(.app-window-card) {
  transform: none;
}
```
彻底释放卡片的 3D `transform` 控制权，同时大幅收敛微光层的不透明度，将视觉焦点完全归还给卡片的几何倾斜与物理按压。

### (2) 物理翘板几何映射（戳哪沉哪）
计算光标/触控点距卡片中心的归一化距离 $px \in [-1, 1], py \in [-1, 1]$：
- **戳左侧 ($px < 0$)**：$rotY$ 为负（$-14^\circ \sim -22.4^\circ$），**左侧深入屏幕下陷**，右侧翘起；
- **戳右侧 ($px > 0$)**：$rotY$ 为正（$+14^\circ \sim +22.4^\circ$），**右侧深入屏幕下陷**，左侧翘起；
- **戳上方 ($py < 0$)**：$rotX$ 为正（$+9^\circ \sim +14.4^\circ$），**上方深入屏幕下陷**，下方翘起；
- **戳下方 ($py > 0$)**：$rotX$ 为负（$-9^\circ \sim -14.4^\circ$），**下方深入屏幕下陷**，上方翘起。

### (3) 点按戳压深度放大（Press Down）
- 当鼠标左键点下（`mousedown`）或手指戳在屏幕上（`touchstart`）时，下沉倾角**瞬间放大 1.6 倍**，整体卡片配合产生 `scale3d(0.985, 0.985, 0.985)` 微压陷，带来犹如按压实体键盘/机械翘板的软弹手感；
- 手指或鼠标松开时，通过 Apple 弹簧曲线 `cubic-bezier(0.175, 0.885, 0.32, 1.275)` 弹性反弹回位。
