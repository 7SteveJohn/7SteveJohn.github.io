# 全局弹窗常驻顶栏与关闭按钮物理隔离 - 交付记录

## 1. 问题背景与定位

在用户截图中（`posts/two-years-of-flashing.md` 文章阅读弹窗），弹窗右上角关闭按钮（`×`）直接悬浮覆盖在右侧滚动的正文文字上方（出现 `...掉，看文字的时候降 ×` / `办法。最费劲的地` 的字形重叠）。

### 根本原因定位
1. **绝对定位层级重叠**：原本 `index.html` 中的 `#article-modal` 与 `#project-modal` 关闭按钮均采用 `absolute top-4 right-4 z-10` 浮动在 `.modal-panel` 上，而正文容器直接占满整个弹窗高度。
2. **滚动文本贯穿入侵**：当用户向下滚动阅读时，长文本内容行会径直向上滚入 `top: 16px, right: 16px` 区域。
3. **视觉焦点干扰**：按钮虽为半透明，但背景与正文笔画交织，加之聚焦轮廓（Focus Ring）的存在，造成明显的视觉污染与文字遮挡。

---

## 2. 架构重构与改造实施

针对该问题，我们对全站弹窗（文章阅读弹窗 `#article-modal` 及项目规格弹窗 `#project-modal`）进行了**结构级物理隔离**改造：

### 2.1 结构解耦：常驻顶栏与独立滚动容器
- 将 `.modal-panel` 重构为 Flex 垂直流式布局：`flex flex-col max-h-[85vh]`。
- **引入常驻独立顶栏（`modal-top-bar`）**：
  - 放置于弹窗最顶部，设置 `shrink-0 z-20 select-none`，不随正文滚动。
  - 左侧展示：模块分类药丸徽章（如 `技术手记` / `项目详情`）及当前标题省略文本预览（`#article-bar-title` / `#project-bar-title`），让读者在长文滚动中始终保持上下文感知。
  - 右侧展示：专属关闭按钮 `modal-close-btn`，内置标准 16px 矢量 SVG 关闭图标，具备清晰轮廓、平滑悬浮微交互与独立焦点环，绝不与任何正文发生空间重合。
  - 顶栏底边直接承载全局阅读进度条（`#article-progress`），进度随阅读深度平滑延伸。
- **独立内容容器**：
  - 正文容器（`#article-modal-content` 与 `#project-modal-content`）设置为 `flex-1 overflow-y-auto overscroll-contain`。
  - 正文只能在顶栏下方的独立视口内滚动，所有文字行从物理结构上根本无法滚入顶栏区域，从根源上 100% 杜绝了文字与关闭按钮的碰撞重叠。

### 2.2 视觉与暗色模式适配（`css/style.css`）
- `.modal-top-bar` 引入苹果风格的毛玻璃模糊与边框层次：
  - 浅色模式：`rgba(255, 255, 255, 0.94)`，配合 `backdrop-filter: blur(20px) saturate(1.4)` 与细腻下边框 `border-black/8`。
  - 深色模式：`rgba(22, 22, 23, 0.94)`，配合深色亚克力磨砂质感与细腻下边框 `border-white/8`。
- `.modal-close-btn` 设立 32x32px 舒适点击热区，内敛圆角微边框，支持 `:focus-visible` 优雅高亮而不影响周边元素。

### 2.3 状态同步与动效联调（`js/app.js`）
- 在 `openArticleModal` 和 `openProjectModal` 打开函数中，同步提取并绑定顶栏的标题与分类文本。
- 保证文章切换时标题、分类及阅读滚动位置（重置为 `scrollTop = 0`）精准归位。

## 3. 测试与验证结果

1. **桌面端与移动端响应式测试**：
   - 桌面端视口（1440x900）：顶栏平铺，标题与分类舒展呈现，正文大幅滚动时与关闭按钮物理间隔充足。
   - 移动端视口（375x812 iPhone 尺寸）：分类徽章通过 `shrink-0 whitespace-nowrap` 锁定不折行，标题自动省略（`truncate`），关闭按钮稳定驻留在右上角独立安全区，正文滚动顺畅无冲突。
