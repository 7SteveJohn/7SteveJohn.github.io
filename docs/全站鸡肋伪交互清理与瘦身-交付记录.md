# 全站鸡肋伪交互清理与瘦身 · 交付记录

> 交付日期：2026-11-18  
> 涉及模块：`js/app.js`、`js/particles.js`、`scripts/build-bundles.mjs`、`css/style.css`、`sw.js` 及 6 个 HTML 入口页

---

## 1. 背景与清理原则

根据实际体验审视，剔除站内「无实际业务用途、仅往访客本机写 `localStorage` 并弹 Toast 自嗨、或干扰原生阅读复制」的伪交互与历史死代码，仅保留真正服务于阅读与下载的实用能力（以及首屏不打扰的时段问候语）。

---

## 2. 已移除的 9 项鸡肋功能与死代码清单

| 序号 | 移除项 | 原位置 | 移除原因 |
|---|---|---|---|
| 0 | 正文划词「写下你的批注（仅保存在本机）」 | `js/app.js` (`initAnnotations`)、`css/style.css` (`.sj-popover` / `.sj-note`) | 划选文字松手即弹窗并调用 `textarea.focus()` 抢夺焦点，导致读者无法正常 `Ctrl+C` 复制技术命令与正文，且仅存本机无实际价值 |
| 1 | 文章底部情绪按钮「这一篇给你的感觉（仅存本机）」 | `js/app.js` (`EMOTIONS` / `[data-emotion]`)、`css/style.css` (`.emotion-btn`) | 无后端统计汇总，点击仅写本机 `localStorage` 并弹 Toast，纯伪互动 |
| 2 | 文章滚到底自动弹 Toast `读完了，谢谢你 ❤` | `js/app.js` (`initArticleProgress`) | 每次滚至文末弹出黑条遮挡翻页栏与相关阅读；保留顶栏阅读进度细条本身即可 |
| 3 | Konami 键盘彩蛋（`↑↑↓↓←→←→BA` 粒子庆典） | `js/app.js` (`initKonami`)、`js/particles.js` (`particlesParty`) | 常驻全局 `keydown` 比对序列，触发仅弹 Toast 变色 20 秒 |
| 4 | 个人状态仪表盘 `#hero-status` | `js/status.js`、`js/app.js` (`initHeroStatus`)、`index.html` | 数据源三项字段长期全空，每次进站空跑逻辑且永远隐藏 |
| 5 | 文章「版本回溯（`revisions`）」切换逻辑 | `js/app.js` (`versionedContent` / `[data-version]`) | 全站 21 篇 `posts/*.md` 从未配置过 `revisions` 字段，100% 未触发死代码 |
| 6 | 已废弃的阻尼滚动残留实现 | `js/app.js` (`initDampedScroll` / `enableDampedScroll`) | 早已停用回退原生滚动，约 75 行死代码白占首屏包体积 |
| 7 | 长按 `Tab` 键 180ms 弹出「快速导航」浮层 | `scripts/build-bundles.mjs`（移出 `core`）、`css/style.css` (`#tabnav`)、`archive.html` 文案 | 无显著视觉入口、移动端无 Tab 键，且与 `Ctrl+K` 搜索面板及顶栏导航重叠 |
| 8 | 左下角常驻齿轮「显示设置面板」 | `scripts/build-bundles.mjs`（移出 `core`）、各 HTML `<link href="css/settings-panel.css">`、`sw.js` `CORE` | 访客几乎不会手动拉滑块调节博客背景壁纸模糊度，移除后消除左下角常驻悬浮干扰并少 1 个阻塞样式请求 |

## 3. 明确保留的实用能力

- **首屏时段感知问候语**（`initHeroGreeting`，如「清晨好 / 午间安适 / 夜深清寂，慢慢看」）：安静展示、不弹窗不打扰。
- **点击「网盘下载」自动复制提取码并右上角轻提示 `已复制提取码: xxxx`**：全站唯一保留的 Toast，跳转蓝奏云/百度网盘后直接粘贴即可。
- **代码块右上角一键复制、`Ctrl+K` 站内搜索、长文自动目录（TOC）与阅读进度细条、上下篇翻页与相关阅读**。
