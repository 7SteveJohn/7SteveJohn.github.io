## 1. 变更背景与核心目标

用户需求聚焦于进一步优化现有布局节奏与增补实用交互功能：
1. **旗舰产品卡片宽屏排版防截断**：先前宽屏桌面端 `#products > article.bento-card` 的 `margin-bottom: 26vh;` 在 768px~900px（日常笔记本、1080p 缩放屏）下因外边距过大，滚动到卡片时底部按钮组与操作栏容易被视口下边缘切断。需将其收拢为自适应弹性呼吸间距，微调内部内边距与视窗视频高度上限，确保 768px~1080p 任何标准屏幕下一卡自洽完整呈现。
2. **归档页（`archive.html`）时间河全面清退“无用小框”**：彻底拔除 `.arc-pill` 的 `border` 与 `background`，统一为纯净的高级内联文字排版（如 `技术手记 · 2026-10-18 · 4 分钟`），与首页彻底去框风格 100% 统一。
3. **滚动浮现（`.reveal`）淡入平滑度调优**：优化触发阈值与边距（`rootMargin: '0px 0px 40px 0px'`, `threshold: 0.05`），避免视口边缘卡片发灰半隐匿。
4. **全局搜索快捷键补强**：强化 `Ctrl + K` / `⌘K` 一键呼出搜索命令面板并自动居中聚焦，支持 `Esc` 退出；次级页面按快捷键无缝直达首页搜索；顶栏增设桌面端键盘提示徽标。
5. **网盘下载“提取码自动复制 + 极轻量 Toast 提示”**：点击「网盘下载 (提取码: xxx)」按钮时，自动将提取码写入剪贴板，并在右上角弹出 1.5 秒微弱优雅的 Toast 提示（如“已复制提取码: xxx”），跳转网盘后直接 Ctrl+V。
6. **长文阅读弹窗流动进度条**：文章常驻顶栏底边接入极细微流动微光阅读进度条，随弹窗内滚动实时更新百分比与视觉辉光。
7. **正文代码块微语言徽标与反馈**：正文中的代码块增设左上角微语言徽标（如 `PYTHON`、`JS` 等），一键复制按钮提供 `✓ 已复制` 状态反馈与绿意高亮样式。

## 4. 深度复核与加固清单

在后续严格代码审计与边界对抗中，发现并修复了以下 6 项关键隐患：
1. **次级页面遗留 3D 物理倾斜与轮询定时器彻底清理**：
   - `archive.html` 与 `gallery.html` 遗留有内联 `init3DArchiveTilt` / `init3DGalleryTilt` 脚本，不仅导致悬停破坏极简 Apple 风格微抬样式，还每秒执行 `setInterval(..., 1000)` 造成无意义的常驻轮询定时器。已彻底将其从两页中拔除。
2. **长代码横向滚动按钮飘移缺陷**：
   - 原先语言徽标与复制按钮直接绝对定位挂载在具备 `overflow-x: auto` 的 `pre` 元素内。当读者横向滚动查看长代码时，按钮会随着内容向左滑入视野外或叠在代码上。现重构为 `.code-wrap` 独立定位外壳包裹 `pre`，使代码在内层自由横向滑动的同时间，右上角与左上角按钮/徽标绝对稳固置顶。
3. **Esc 快捷键穿透导致底层弹窗误关**：
   - 当在文章或项目弹窗中呼出 `Ctrl+K` 搜索面板并按 `Esc` 退出时，原事件未调用 `stopImmediatePropagation()`，导致 `app.js` 的全局 Esc 监听器一并触发，将底层阅读文章同时关闭。现升级为 `e.stopImmediatePropagation()` 彻底阻断同级穿透。
4. **次级页面顶栏增设搜索快捷入口**：
   - 移动端或无实体键盘访问 `archive.html` 和 `gallery.html` 时无法按下 `Ctrl+K`。现为两页吸顶导航统一补全与首页一致的高级搜索胶囊按钮，触屏和桌面均可一触直达。
5. **代码复制按钮连续高频连击定时器冲突**：
   - 修复了 1.5 秒内连续点击复制按钮时前次定时器未清除导致的提前跳回「复制」文案的问题。
6. **次级页深链唤起搜索保留原有参数**：
   - `?search=1` 在打开搜索面板后清除参数时，改用保留原有 query 参数的精细化重构，防止已有参数丢失。
