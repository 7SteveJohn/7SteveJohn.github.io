# 卡片真·悬浮动效与全域极简视觉重构 — 交付记录

## 1. 用户反馈与深层根因定位
在用户反馈“你卡片那个物理倾斜效果，你就是没有加上呀”后，我们通过对浏览器渲染流水线、CSS 层叠样式、次级页面与 Service Worker 缓存机制的全面深度排查，定位到导致该体感的两大深层机制根因：

1. **根因一：Service Worker 历史导航策略（SWR 先读缓存）导致客户端死锁在旧版本**
   - 此前 `sw.js` 针对页面导航（`req.mode === 'navigate'`）采用了 SWR 策略：先直接将本地 CacheStorage 中已有的 `index.html` 返回给浏览器，后台才去异步拉取新版并覆盖缓存；
   - 结果导致用户在浏览器中无论如何按普通刷新，打开的始终是旧版本的缓存页面，旧页面中请求的也是老版本的 bundle，新加入的 3D 悬浮代码在用户端根本没有被加载执行。
2. **根因二：缺少纯 CSS 级别的立即上浮保底态**
   - 依赖纯 JavaScript 的 `mousemove` 监听时，在光标刚移入、尚未产生有效坐标位移前，卡片处于“无状态”；
   - 现为 `.bento-card:hover` 注入原生的 `transform: translateY(-8px)`，光标移入的瞬间即便不移动，也能即刻获得轻盈上浮响应。
3. **根因三：多层分包异步加载时序脱节**
   - 此前逻辑分布在 `site-config.js` 与 `app.js` 内部，容易受 bundle 执行时钟或 `DOMContentLoaded` 拦截影响。

## 2. 彻底根治与终极方案落地

### 2.1 Service Worker 升级为“网络优先（Network-First）”导航
修改 `sw.js`：
```js
// 页面导航采用网络优先策略：在线时永远即时拉取最新代码与版本，离线时秒级回退离线缓存
fetch(req)
  .then((res) => {
    if (res && res.ok) {
      const copy = res.clone();
      caches.open(CACHE).then((cache) => cache.put(key, copy));
    }
    return res;
  })
  .catch(() => caches.match(key).then((cached) => cached || offlineFallback('离线：页面未缓存')));
```
- 缓存键升级至 `sevenjohn-v236`；
- 所有静态资源版本号递增至 `?v=20261106_v236`；
- 用户端只要在线，刷新即可 100% 立即获取最新 HTML 与最新静态资源。

### 2.2 页面级直接内联 3D 物理微倾斜引擎
在 `index.html`、`archive.html`、`gallery.html` 页面底部直接内联原生 3D 微倾斜交互，零时序依赖、零外部文件拦截：
```js
card.addEventListener('pointermove', function (e) {
  const rect = card.getBoundingClientRect();
  const x = e.clientX - rect.left - rect.width / 2;
  const y = e.clientY - rect.top - rect.height / 2;

  const rotX = (y / (rect.height / 2)) * -6.0;
  const rotY = (x / (rect.width / 2)) * 10.5;
  const shadowX = (rotY / 10.5) * -20;
  const shadowY = 22 + (rotX / 6.0) * 6;

  card.style.transform = 'perspective(750px) rotateX(' + rotX.toFixed(2) + 'deg) rotateY(' + rotY.toFixed(2) + 'deg) translateY(-8px) scale3d(1.015, 1.015, 1.015)';
  card.style.boxShadow = shadowX.toFixed(1) + 'px ' + shadowY.toFixed(1) + 'px 36px -8px rgba(37, 99, 235, 0.22), ...';
});
```
- 左右最大倾斜 `±10.5°`，上下微倾 `±6.0°`，悬浮抬升 `-8px`；
- 动态光斑与反向物理深度投影同步位移；
- 鼠标移出时光滑弹性衰减回正。

### 2.3 CSS 基础浮动保底
在 `css/style.css` 中为 `.bento-card:hover` 与 `.app-window-card:hover` 显式声明：
```css
html:not(.dark) .bento-card:hover {
  transform: translateY(-8px);
  border-color: rgba(37, 99, 235, 0.38);
}
.dark .bento-card:hover {
  transform: translateY(-8px);
  border-color: rgba(56, 189, 248, 0.45);
}
```
