# 卡片真·悬浮动效与全域极简视觉重构 — 交付记录

## 1. 用户反馈与痛点审视
针对用户针对上一版视觉提交提出的关键反馈与截图：
1. **去除生硬套壳元素**：“你为什么要给左上角加个 Apple 的那种元素？”
   - 彻底删除产品卡片上强行套用的 macOS 假红黄绿交通灯（`.traffic-lights`）与假视窗标题栏（`.window-header`）；
   - 彻底去除产品区顶部的冗余悬浮切换栏（`.product-tabs-bar`），消除双层工具栏带来的严重割裂感与视线杂乱；
2. **落实真正的卡片悬浮状态 (Floating State)**：“我说的是卡片选择要有那种悬浮的状态，你知道吧？卡片的效果呢像这个文件里面的这种悬浮效果@[demo-linear-apple.html]”
   - 精准提取并融合 `demo-linear-apple.html` 的物理级悬浮动效（`translateY(-4px)` 配合 `box-shadow: 0 20px 45px -12px rgba(37, 99, 235, 0.14)` 与边框微蓝光）；
   - 注入真实鼠标 3D 景深物理倾斜（`perspective(1000px) rotateX(...) rotateY(...) translateY(-4px)`），随鼠标移动细腻倾角反馈，移出后平滑回弹；
3. **彻底修复首屏作品索引换行缺陷与选中美感**：“第三张图片的选择状态也不是很好看”
   - 原先在窄桌面屏幕下 `04 Fluxion` 被孤零零挤到第二行，造成极其不对称的 3 + 1 丑陋折行；
   - 彻底重构布局：桌面及平板端强制 `flex-wrap: nowrap`，4 个工具在单行绝对居中横排；移动端（≤640px）自适应为 2×2 对称四宫格，彻底告别单项孤立折行；
   - 选中态去除突兀的偏移动作，采用优雅上浮 `translateY(-2px)` 与微透白底晶片投影，自然克制；
4. **左右双栏并列与单屏完整呈现**：
   - 桌面端（≥860px）卡片采用标准双栏并列（左侧文案标签与操作胶囊，右侧硬件级 16:9 播放预览）；
   - 卡片整体高度控制在 360px~400px，全屏任何标准分辨率下均能一屏完整呈现，卡片四周留白完全透出背后的 3D 神经网络粒子光球；
5. **弹窗与二级页面去噪极简 (Minimalism)**：“二级页面要求的就是简约，因为你已经有很多文字了，你知道吧”
   - 移除弹窗关闭按钮获取焦点时生硬刺眼的亮青色方框轮廓；
   - 修复 `css/archive.css` 历史残留的非法闭合花括号语法错误；
   - 归档（`archive.html`）与照片墙（`gallery.html`）保持呼吸感充盈，单列技术手记与时间轴清晰易读，相册网格缩放与浮光微交互丝滑优雅。

## 2. 核心代码改造细节

### 2.1 彻底精简卡片结构与移除伪视窗 (`index.html`)
- 删除了 4 张核心卡片内部的 `<div class="window-header">` 伪交通灯结构，回归纯粹极简的内容呈现主体；
- 卡片仅保留两大主栏：
  - 栏目一（左侧）：分类徽标、产品标题、最新版本公告单行微胶囊、技术难点与简介、技术栈标签、操作按钮组（网盘下载 / GitHub Releases / 了解更多）；
  - 栏目二（右侧）：精巧硬件感 16:9 视窗播放器；
- 卡片四周留白通透，彻底透出居中的 3D 神经网络粒子球。

### 2.2 顶级真·左右悬浮动效规范 (`css/style.css` & `js/app.js`)
- **静止状态**：通透半透明液态磨砂玻璃（`rgba(255, 255, 255, 0.85)` / 深色 `rgba(16, 22, 34, 0.75)`），轻柔微晶轮廓与深层柔和投影；
- **动态光泽层 (`::before`)**：光标在卡片左右移动时投射自然柔和的漫射流光（`radial-gradient` 伴随 `--mouse-x`, `--mouse-y`）；
- **60FPS RAF Lerp 3D 物理倾斜引擎**：
  - 彻底剥离 CSS `transition: transform` 造成的 300ms 滞后对抗，改由 `requestAnimationFrame` 以 `0.22` 的插值比率实现极速零延迟跟手；
  - 左右倾斜幅度强化至 `±7.5°`，上下倾斜微调至 `±4.5°`，悬浮上浮提升至 `-8px`，光标向左/向右划过时，卡片呈现极具物理立体感与弹性質感的轻盈左右微翘；
  - 移出时光标平滑衰减弹簧复位，杜绝生硬回弹。

```js
// 左右倾角最大可达 ±7.5°，上下 ±4.5°
targetRotY = (x / (rect.width / 2)) * 7.5;
targetRotX = (y / (rect.height / 2)) * -4.5;
currentRotX += (targetRotX - currentRotX) * 0.22;
currentRotY += (targetRotY - currentRotY) * 0.22;
currentElev += (-8 - currentElev) * 0.20;
card.style.transform = `perspective(1000px) rotateX(${currentRotX.toFixed(2)}deg) rotateY(${currentRotY.toFixed(2)}deg) translateY(${currentElev.toFixed(2)}px) scale3d(1.015, 1.015, 1.015)`;
```

### 2.3 首屏作品索引优雅重构 (`#home .hero-index`)
- 采用 `flex-wrap: nowrap; max-width: 880px;`，确保 4 款工具在桌面屏幕始终处于单行绝对居中对称，绝不再单项换行；
- 在小屏幕移动端（≤640px）自适应为 2×2 对称四宫格网格，两两对称，规整耐看；
- 选中态去除突兀的 `translateX(4px)`，采用优雅上浮 `translateY(-2px)` 与微透白底晶片投影，自然克制。

### 2.4 弹窗与更新记录简约高质感重塑 (`css/style.css` & `js/app.js`)
- 移除 `.modal-close-btn` 上的强聚焦青色轮廓（`outline: none !important`）；
- 弹窗顶栏精简为轻盈分类胶囊与纯正字重标题；
- 彻底优化更新记录明暗对比：
  - 浅色模式文字采用高对比度的 `#1e293b`（标题）与 `#475569`（正文），行高提升至 1.7；
  - 版本号采用清爽的端侧蓝晶小微标；
  - 细线边框采用淡雅的微透明度，文字层级一目了然。
