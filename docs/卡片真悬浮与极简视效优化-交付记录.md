# 卡片真·悬浮动效与全域极简视觉重构 — 交付记录

## 1. 用户反馈与深层根因定位
在用户反馈“你还是没有做到卡片那左右悬浮的感觉”、“没有啊？”、“还是没有，要不你优化一下”后，我们通过对浏览器渲染流水线、CSS 层叠样式、次级页面与首屏交互的深度排查，定位到 4 大真实病灶：

1. **病灶一：`.reveal` 的 500ms 补间动画严重抹除与迟滞了 Transform**
   - 页面中的产品卡片全部带有 `.reveal` 进场动效类，而全局样式中 `.js .reveal.is-visible` 定义了 `transition: transform 0.5s var(--ease-swift)`；
   - 当鼠标在卡片上移动时，浏览器每帧赋予的 `transform` 都在与底层 500ms 的缓动曲线对抗拉扯，导致高频左右微倾斜被抹平为极迟钝的微动，用户在肉眼上感知为“完全没有悬浮随动”。
2. **病灶二：缺少物理动态反向阴影（缺少悬空厚度感）**
   - 单纯微小的 `rotateY` 只是平面投影变形，缺乏真实光源反差；
   - 真正高级的 Linear / Apple 质感必须配合“卡片向左翘起时，阴影向右侧深投；向右翘起时，阴影向左侧深投”，有了光源反差与阴影位移，悬浮感瞬间凸显 10 倍。
3. **病灶三：二级页面（归档与照片墙）完全未挂载倾斜动效**
   - 用户在多轮反馈中持续提及“这两个选项下面的二级页面你没有进行修改”、“二级页面要求的就是简约，我说的是卡片选择要有那种悬浮的状态”；
   - 原先的倾斜监听仅被写在首页 `app.js` 内，次级页面 `archive.html`（时间轴文章卡片）与 `gallery.html`（照片墙瓷砖）没有任何 3D 浮动事件监听。
4. **病灶四：首屏作品索引选中态视觉粗糙**
   - 用户截图指出的“第三张图片的选择状态也不是很好看”，原先激活项呈现出类似方形实色色块的生硬感，破坏了首屏轻灵通透的氛围。

## 2. 全面优化与重构方案

### 2.1 全局拟物 3D 物理左右悬浮引擎 (`root.attach3DTilt`)
在 `js/site-config.js`（编译进入 `core.js`，全站共享）收口沉淀通用微倾斜引擎：
- **倾角与景深升级**：
  - 首页产品大卡：`perspective(850px) rotateY(±10.0°) rotateX(±6.5°) translateY(-8px)`；
  - 归档页文章卡片：`perspective(750px) rotateY(±8.5°) rotateX(±5.5°) translateY(-5px)`；
  - 照片墙瓷砖：`perspective(800px) rotateY(±9.0°) rotateX(±6.0°) translateY(-6px)`；
- **动态物理阴影投射**：
  ```js
  const shadowX = (rotY / maxRotY) * -18;
  const shadowY = 18 + (rotX / maxRotX) * 6;
  card.style.boxShadow = `${shadowX.toFixed(1)}px ${shadowY.toFixed(1)}px 32px -8px rgba(37, 99, 235, 0.18), ...`;
  ```
- **CSS 补间与 GPU 加速契约**：
  在 `style.css`、`archive.css`、`gallery.css` 中显式指定：
  ```css
  transition: transform 0.22s cubic-bezier(0.16, 1, 0.3, 1), box-shadow 0.25s ease, border-color 0.25s ease !important;
  transform-style: preserve-3d;
  will-change: transform, box-shadow;
  ```
  通过 `!important` 彻底阻断 `.reveal` 的 500ms 迟滞污染，并以精准的 `0.22s cubic-bezier` 呈现媲美原生 App 的微弹性跟手与回弹体验。

### 2.2 二级页面（归档与照片墙）全量激活与极简视觉打磨
1. **归档页 (`archive.html` / `archive.js` / `archive.css`)**：
   - 时间轴上所有手记卡片（`.arc-card`）接入 3D 微倾斜交互；
   - 增加卡片表面动态微光跟随（`::before` 配合 `--mouse-x`, `--mouse-y`）；
   - 去除多余视觉装饰，专注黑白灰与晨曦蓝的精雅对比，文字排版舒适易读。
2. **照片墙 (`gallery.html` / `gallery.js` / `gallery.css`)**：
   - 混排网格内所有照片瓷砖（`.gal-tile`）动态接入 3D 微倾斜左右悬浮交互；
   - 光标悬停时瓷砖微扬，深层柔光投影铺展，图片微妙缩放 `scale(1.035)`，高阶艺术画廊质感。

### 2.3 首屏作品索引液态磨砂控制台 (`#home .hero-index`)
- 布局升级为一体化液态磨砂胶囊底座：
  - 浅色：`rgba(255, 255, 255, 0.72)` + 16px 背景模糊 + 极细柔和边框；
  - 深色：`rgba(15, 23, 42, 0.65)` + 16px 背景模糊；
- 4 款工具横向单行排列、无折行挤压；
- 激活选中态化身浮雕感白晶按键，投射轻柔环境阴影，数字与版本标以极客蓝（`#2563eb`）精准点缀，克制优雅。
