# 卡片真·3D物理悬浮倾斜与视差景深重构 — 交付记录

## 1. 深度根因排查与定位

在用户再次明确指出：“说的是给这种卡片加入3D效果呀，你怎么没加入呢”（指向首页 4 款核心旗舰产品卡片：FileButler、拍案、NetOps、Fluxion）后，我们通过对浏览器 3D 渲染管线、CSS 3D 上下文合并规则以及事件调度生命周期进行了像素级深度逆向排查，彻底查清了用户在真实屏幕上“感知不到 3D 倾斜”的三重底层死锁根因：

1. **根因一：`overflow: hidden` 强制展平了浏览器的 3D 渲染上下文（CSS Spec 3D Flattening）**
   - 首页 4 款大卡均硬编码了 `class="bento-card reveal overflow-hidden"`，同时 CSS 中 `.bento-card` 也声明了 `overflow: hidden`；
   - 根据 W3C CSS Transforms Module Level 2 规范，任何赋予了 `overflow: hidden` 的元素都会在其内部建立强制分组上下文（Grouping Context），直接将所有的 `transform-style: preserve-3d` 扁平化为 2D 贴图！导致卡片在旋转时仅发生微弱的 2D 矩形剪切变形，完全无法呈现真实的 3D 空间体积感。

2. **根因二：父级容器 `#products` 缺失 3D 透视视锥（Missing Parent Perspective）**
   - 此前 `perspective: 1000px` 仅声明在卡片自身上。在 CSS 渲染管线中，元素自身的 `perspective` 只对其子元素生效，对卡片自身在全屏中的立体透视毫无影响；
   - 976px 超宽卡片在没有外层 3D 视锥时，水平微转动在视网膜屏幕上几乎是平直的。

3. **根因三：`site-config.js` 与 `index.html` 双重监听器时钟冲突与强制清零**
   - `index.html` 底部的 `init3DCardTilt`（`pointermove` + `pointerleave`）与 `site-config.js` 的 `attach3DTilt`（`mousemove` + `mouseleave`）同时在每个卡片上激活；
   - 两套逻辑使用不同的透视距离（750px vs 800px）与不同的倾斜公式，在每秒 60 次的鼠标移动中相互覆写抖动；
   - 更严重的是：`site-config.js` 的 `mouseleave` 一触发就直接执行 `card.style.transform = ''`，硬生生打断了 CSS 的 0.22s 弹性过渡曲线，导致视觉上瞬间“闪回平整”，用户体验为“根本没有倾斜动效”。

## 2. 终极架构重构与质感升级

### 2.1 解除 3D 展平限制与注入全局透视视锥
1. 在 `index.html` 中移除 4 款旗舰大卡（FileButler、拍案、NetOps、Fluxion）上的 `overflow-hidden` 类；
2. 在 `css/style.css` 中为 `#products` 挂载全局 3D 视锥摄像机：
```css
#products {
  perspective: 1200px;
  perspective-origin: center;
  transform-style: preserve-3d;
}

#products > article.bento-card {
  border-radius: 1.25rem;
  transform-style: preserve-3d !important;
  will-change: transform, box-shadow;
  transition:
    transform 0.22s cubic-bezier(0.16, 1, 0.3, 1),
    box-shadow 0.25s cubic-bezier(0.16, 1, 0.3, 1),
    border-color 0.25s ease;
}
```

### 2.2 统一单例高性能 RAF 物理 3D 微倾斜引擎
在 `js/site-config.js` 中重写 `root.attach3DTilt`，全面接管全站所有卡片的物理 3D 悬浮：
- **更具物理实体感的大倾角**：水平最大旋转倾角调至 `±11.5°`，垂直倾角 `±7.0°`，悬浮离地抬升 `-10px`，等比浮凸缩放 `1.018`；
- **单例 `requestAnimationFrame` 驱动**：使用独立 RAF 调度，杜绝事件抖动，保证在 60Hz/120Hz 高刷屏下帧率完全饱满；
- **动态物理反向深度投影**：
  - 光标向左下压时，阴影向右上强力延伸投射（水平位移达 `±22px`，羽化半径 `42px`）；
  - 浅色模式叠加 Linear 级天蓝羽化流光与纯白顶部高光内描边；深色模式叠加黑曜石极深黑影与 `rgba(56, 189, 248, 0.22)` 霓虹边缘外溢光晕；
- **动态玻璃漫射光泽**：实时将 `--mouse-x` 与 `--mouse-y` 注入卡片表面 `::before` 径向渐变光晕，光泽随鼠标游走流动；
- **丝滑物理回弹**：移出时光滑过渡回 `perspective(950px) rotateX(0deg) rotateY(0deg) translateY(0px) scale3d(1, 1, 1)`，260ms 动画完全平复后才安全释放内联样式；
- **彻底消除多重监听冲突**：`index.html` 与 `app.js` 统一由该单例引擎驱动，通过 `card.__hasTiltEngine` 强幂等保证每张卡片只绑定一套监听器。
