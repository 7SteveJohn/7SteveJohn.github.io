## 一、 背景与重塑目标

在过往的产品展示中，部分描述倾向于功能清单式的铺陈，未能在第一时间抓住读者的眼球，降低了产品的吸引力与冲击力。本次改造严格依照用户指令——**“每一个产品都要把它们的卖点展现出来，而不是循规蹈矩，这样卖点太小了，吸引不到用户的眼球”**，进行全方位的视觉、听觉与文案革新：

1. **拍案 (PaiAn)**：
   - 聚焦长篇网文作家最痛的“卡文”与“签约过审”两大现实痛点；
   - 突出**独创码字抽卡激励体系**（码字净产出换抽卡，抽取 N~SSR 四级灵感卡牌专治卡文，新卡进手牌，重复卡转墨）与**网文体检四页签**（敏感词排查、口头禅雷达、长段对白比合规）；
   - 在 1080p Apple 风格宣传片中加入专门的高光抽卡场景：金色光柱爆发（`gacha-beam r-SSR`）、舞台聚光灯聚焦、卡背朱红「创」字印章翻转揭晓闪耀的【SSR · 大局】灵感手牌，并伴随清脆的金光音效与 Lo-Fi 节拍。
2. **FileButler (本地文件管家)**：
   - 摆脱普通的“文件管理”口吻，突出**不挑配置**（云端 API Key + 本地模型双轨自选）；
   - 突出发票/扫描件/截屏直接搜图内文字（**OCR 穿透秒搜**）、文档不用打开直接问出处并定位页码（**免开文档问答 RAG**）、智能整理“先出方案预览确认后再动”（**全流程无损一键撤销**）。
3. **Fluxion (竞技级游戏性能套件)**：
   - 突出**打破代际锁死限制**：让 RTX 20/30 系老显卡强开 DLSS 帧生成（实测《赛博朋克 2077》从 120 FPS 翻倍至 280 FPS）；
   - 突出 **51 项底层体检**专治交火瞬间 1% Low 掉帧卡顿与输入延迟；
   - 突出与游戏进程联动：**进游戏自适应调优，退出瞬时无感还原**，日常办公零影响。
