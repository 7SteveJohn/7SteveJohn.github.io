## 1. 软件更新与技术对齐

| 模块 | 更新前状态 (v1.3.0) | 更新后状态 (v1.3.1) | 优势与收益 |
| :--- | :--- | :--- | :--- |

| **安装包与交互体验** | 缺少部分语言配置可能弹出二次语言选择弹窗 | Inno Setup 语言包自闭环，自动匹配 Windows 系统语言直达安装界面；清理 UI 网聊/AI 机械味术语 | 安装与配置零废话，更符合工业级原生应用标准 |
