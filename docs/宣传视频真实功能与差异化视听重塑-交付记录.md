## 二、音频引擎全量重塑 (`Temp/make_apple_soundtrack.py`)

为了使两部视频彻底摆脱同质化，重构了纯信号处理合成器引擎：

### 1. FileButler：Warm Neo-Soul Tech Groove (114 BPM)
- **和声进程**：$D\flat\text{maj9} \to \text{Fm9} \to \text{B}\flat\text{m9} \to \text{E}\flat\text{9sus}$；
- **核心器乐**：Rhodes 电钢琴（基频 + 泛音 + 金属性 Tine 敲击瞬态 + 立体声 Tremolo）、温暖圆润的模拟指弹贝斯（220Hz 柔和低通）、有机木质 Rimshot、58% Swing 摇摆高频闭合踩镲；
- **同步 Foley**：
  - 键入「年度预算」时，在 6.1s ~ 7.4s 同步触发 4 次真实剪刀脚/机械轴敲击音（带 $\pm 6\%$ 音高微颤）；
  - 搜索命中时刻触发 1200Hz 晶莹清脆音效；
  - 问答交互、整理确认与云端/本地切换节点均具备专属轻音。

### 2. Fluxion：Cyberpunk / 80s Darksynth Future Bass (124 BPM)
- **彻底剔除 Rhodes 电钢琴**，全盘换装赛博朋克与电子游戏硬核音色；
- **重低音工业底鼓 (Industrial Kick)**：基频自 180Hz 骤降至 38Hz，配合过载削波饱和 (`np.tanh(x * 2.1)`)；
- **16分音符驱动 Supersaw 贝斯**：双路失谐锯齿波振荡器（Detune 0.8%）经由 420Hz 谐振低通滤波器与重度饱和，营造如同《赛博朋克 2077》Rebel Path 的狂暴低频推力；
- **80s Gated 赛博军鼓**：190Hz 下扫音色叠加 1.1k~7.5kHz 门控白噪声瞬态；
- **霓虹方波琶音器 (Neon Arp)**：带 PWM 脉宽调制的方波 Lead，随和弦在十六分音符上连续盘旋；
- **转速表极速升效 (Tachometer Rev Sweep)**：在帧生成段落（23.5s ~ 26.5s），音频频率由 120Hz 连续跃升至 280Hz，并在触顶瞬间释放重击（Sub-impact Drop）与高透水晶泛音。

## 六、深度代码与像素级复审及缺陷修复记录 (Review & Fixes)

在独立对前期产出进行逐帧切片审查与声画对齐排查中，发现并彻底修复了以下 4 项关键缺陷：

1. **Fluxion Cyberpunk 2077 详情面板右下旧幽灵文字重叠**：
   - **问题定位**：`gen_cp_details_v2.py` 中清理旧版文字时，擦除矩形仅设定到 `y=930`，而原底图在 `y=938` 处包含一行旧文字 `启动参数: 未设置`，导致画面在打印新参数 `-skipStartScreen -profile=HighPerf` 的下方出现前后矛盾的重影冲突行。
   - **修复落地**：擦除区域纵向延展至 `y=955`，彻底清除残留幽灵文字；同时为「适配方案」下拉选择框补全右侧折叠下拉箭头 `v`，并将 Cyberpunk 2077 封面卡片裁剪由 `(836, 558, 1000, 804)` 调整为完整像素边界 `(836, 558, 1005, 811)`（补全右边框与底角圆角）。

2. **FileButler 自然搜索定位行严重错位（误高亮 `main.py`）**：
   - **问题定位**：`render_fb_apple.py` 中，用户模拟键入「年度预算」，高亮目标应为第 4 行的 `2026年度预算表.xlsx`，但脚本计算坐标为 `WIN_Y + int(432 * scale)`，高亮绿框直接盖在了第 3 行 `main.py` 上，产生“搜年度预算却命中代码文件”的严重逻辑硬伤。
   - **修复落地**：重测 `02-files.png` 中各表格行像素，将目标纵坐标纠正为 `WIN_Y + 505`，精准对齐第 4 行 `2026年度预算表.xlsx`，并将光标移动终点同步移至该行中央。

3. **FileButler 结果高亮绿框横向溢出视窗**：
   - **问题定位**：原高亮框宽度硬编码为 `int(1120 * scale) = 1254px`，起始坐标在 `WIN_X + 267`，右边界延伸至 `1521px`，直接穿透并探出 1400px 宽度的白色卡片右边缘 120 余像素。
   - **修复落地**：匹配表格在原图中的真实宽度（`x=200` 至 `x=1197`，净宽 `997px`），高亮框重塑为 `row_x = WIN_X + int(200 * scale)`、`row_w = int(997 * scale) = 1116px`，右侧保留 60px 边距，无任何溢出。

4. **FileButler 声画打字微秒级错位与旧侧边栏文案残留**：
   - **问题定位**：音频打字声在 6.12s 起步，原脚本字符出现时间在 6.52s，导致 0.4s 声画不同步；且窗口左侧栏顶层写有旧版「本地智能文件管家」、左下角标注「v1.4.2 · 全本地」，与去死板化要求冲突。
   - **修复落地**：将逐字出现时间精准绑定至 `[0.02, 0.45, 0.85, 1.25]`（对应全局 6.12s, 6.55s, 6.95s, 7.35s），7.8s 同步触发匹配提示音；在 `build_hardware_window` 中动态净化侧边栏，将文案统一更迭为「智能文件检索管家」与「v1.4.3」。

5. **FileButler 搜索结果命中胶囊在运镜缩放时被右边缘截断削切**：
   - **问题定位**：`render_fb_apple.py` 中，匹配胶囊横坐标硬编码在 `row_x + row_w - 290 = 1310`，其宽度 270px，右边界达 `x = 1580`。在 `t >= 3.2s` 时运镜向左平移（`cam_cx ≈ 730`）并缩放 1.28x，屏幕可视右边界仅至 `x = 1480`，导致胶囊右端文字「呈现」被生硬削切 100 像素。
   - **修复落地**：将匹配胶囊位置向内收至 `row_x + row_w - 340`，同时将摄像机变焦温和收敛至 1.16x、平移阻尼至 0.18，使整个 1400px 视窗及「匹配: 文件名命中 · 毫秒级呈现」徽标 100% 完整舒展呈现在视野内，右侧保留充裕呼吸空间。

6. **Fluxion Cyberpunk 2077 详情页 [概览]/[参数]/[诊断] 标签栏双重幽灵重影**：
   - **问题定位**：底图 `real_dark_p2_h1000_s-1_sel_w1600.png` 原生已在 `(275, 426)` 渲染有高精度的 `[概览] 参数 诊断` 标签条，旧脚本在未清理旧区域的情况下盲目在 `(310, 426)` 叠绘新文字，导致左侧露出一截残余暗色胶囊圆弧 `(`，且与底图文字发生位移重影（呈现 `参数数` 等叠字混乱）。
   - **修复落地**：重构 `gen_cp_details_v2.py`，拔除盲目重绘标签栏的代码，严格限制顶部横幅擦除边界在 `y <= 416`，完整保留原生底图高精度原生标签栏，彻底根除双重残影与叠字重叠。

7. **Fluxion 侧边栏 Cyberpunk 2077 与 Chill with You 游戏缩略图标意外丢失**：
   - **问题定位**：旧脚本在绘制选中/取消选中状态时，使用 `d.rectangle([16, ...])` 粗暴擦除了整个条目区域，将 `x in [20, 44]` 处的游戏黄色 2077 头像与 Lo-Fi 头像连带抹除，导致唯独选中的 2077 条目缺失图标变成空盒。
   - **修复落地**：重构条目绘制流水线，先在擦除前无损切取原生 24x24 图标像素，在绘制完半透明微光边框与文字后将图标精确贴回 `(20, 466)`，完美还原真实 Fluxion 界面质感。

8. **Fluxion 顶部面包屑导航被切碎断裂**：
   - **问题定位**：旧脚本以 `x=250` 为起点擦除整行，横切了 `...` 省略号的第三个圆点并破坏了手柄图标 `🎮` 与「游戏库 · 」，随后手绘「游戏库 · Cyberpunk 2077」导致字体与原生不一致。
