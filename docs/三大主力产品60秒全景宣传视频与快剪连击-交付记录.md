在多轮产品体验与视觉沟通中，用户针对宣传视频提出了明确的方向指引与关键诉求：

2. **NetOps Handbook 暂不动**：由于 NetOps Handbook 的新版本仍在开发迭代中，本次明确要求**暂不编辑 NetOps 视频**，待后续新版本发布时一并重构。
3. **落实方案 B（60 秒全景宣传 + 4 连击高能快剪）**：FileButler、Fluxion、拍案三大主力产品严格按照方案 B 全面扩充并升级为 60.0 秒 1080p 影视级宣传片，并在 37s～50s 黄金时段嵌入**专属 4 连击高能快剪（Montage）**，把各产品此前深藏在技术底层的独家绝活一次性淋漓尽致地展现出来。

### 2.1 FileButler（文件管家 · 60.0s）

- **痛点纠偏**：坚决去除“全走本机 Ollama / 无需 API Key”的陈旧过时强调；展示全面拥抱 Cloud API 与多样化模型接入的开放架构；搜索交互符合真实直觉，输入直观文件名与语义意图。
- **00:00 - 36.5s 核心工作流**：
  - 智能整理工作区与四步流水线（规则扫描、智能重命名、目录归类、标签注入）。
  - 自然语言智能检索展示（真实搜索 `"2024 年度财务审计报告"`），动态展示即时命中匹配文件。
- **36.5s - 49.5s ⚡ 4 连击高能快剪（Montage）**：
  1. **CLIP 跨模态以文搜图**：输入语义词句，直接用语义向量穿透图片像素，瞬间命中海报与摄影作品。
  2. **EXIF 摄影时空轴**：自动提取快门、ISO、焦段与 GPS 地理坐标，按时间线形成智能照片资产树。
  3. **哈希+感知双重排重**：SHA-256 严谨排重搭配 pHash 图像相似度排重，海量重复文件一键秒清。
  4. **动态 Reranker 交叉重排**：端云结合多模型接入，通过 Cross-Encoder 语义深度重排打分，高相关度文档置顶呈现。

  - 六大主流平台（Steam / Epic / WeGame / 战网 / Ubisoft / EA）游戏库秒级聚合。

- **36.5s - 49.5s ⚡ 4 连击高能快剪（Montage）**：
  1. **实时硬件动态曲线**：GPU 显存占用、功耗瓦数与帧生成动态贝塞尔曲线毫秒级监控。
  2. **51 点微米级微调控制台**：超采样倍率与动态锐化多档位调节，帧率翻倍不损画质。
  3. **独家 `d3d12.dll` 注入机制**：底层原生接口调用，无任何反作弊误报（VAC / EAC 白名单兼容）。
