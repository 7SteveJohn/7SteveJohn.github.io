# 二级页面（归档与照片墙）视觉重塑与明暗双模式全量适配交付记录

## 1. 任务背景与核心问题定位

用户在导航栏指出：「这两个选项下面的二级页面你没有进行修改」（指向导航栏的「归档」`archive.html` 与「照片墙`gallery.html`）。

### 历史遗留缺陷排查
1. **浅色模式灾难级对比度缺失（白底白字）**：
   - `css/style.css` 中 `.page-title`、`.subpage-nav-active` 硬编码为 `color: #f5f5f7`（白色），在浅色背景下标题「归档 · 时间河」与「照片墙」直接隐形；
   - `css/archive.css` 中 `.arc-title`（文章标题）、`.arc-pill`（分类药丸）均硬编码为 `#f5f5f7`，文章卡片文字在浅色下无法阅读；
   - 筛选胶囊 `.arc-chip` 边框与文字在浅色模式下失去对比，处于激活态时颜色偏浅。
2. **主题控制失步与缺少切换按钮**：
   - 二级页面顶栏缺失 `#theme-toggle` 主题切换按钮，访客无法在二级页面自由切换明暗模式；
   - `archive.html` 与 `gallery.html` 顶部内联脚本仍使用旧版 `sj.theme-v5` / `obsidian-v1`，直接抹平了首页设定的浅色模式持久化配置；
   - 二级页面共用脚本 `js/subpage.js` 缺少 `initTheme()` 逻辑，无法响应主题切换事件与 View Transitions 圆形扩散动效。
3. **视觉语言未对齐首页 Linear / Apple 旗舰级标准**：
   - 归档波浪曲线 `wave-line`、进度线 `wave-progress`、节点 `wave-node`、年份标 `wave-year` 缺乏浅色微光适配，存在多余空节点；
   - 照片墙瓷砖 `.gal-tile` 缺乏浅色磨砂质感与内发光边框，灯箱弹窗 `#gal-lightbox` 缺乏浅色高质感浮凸与按钮悬浮微动效。

## 2. 核心修改与工程实现

### 2.1 全局次级页外壳规范 (`css/style.css`)
- **标题与排版**：
  - `.page-eyebrow`：浅色模式下采用科技蓝 `#0284c7`，深色下为浅灰蓝 `rgba(158, 176, 202, 0.55)`。
  - `.page-title`：浅色模式采用深石板黑 `#0f172a`（700 字重，-0.02em 字间距），深色模式 `#f8fafc`。
  - `.page-sub` 与重点数据 `b, strong`：浅色模式 `#0284c7`，深色模式 `#c2d96b`。
- **导航当前态高亮 (`.subpage-nav-active`)**：
  - 增加底部动态能量横线，浅色模式 `#0284c7`，深色模式 `#38bdf8`。
- **分类筛选胶囊 (`.arc-chip`)**：
  - 浅色模式采用极细描边 `border: 1px solid rgba(15, 23, 42, 0.1)`、微磨砂白底与悬浮微升；
  - 激活态注入柔和高亮晶体环，解决无对比度问题。

### 2.2 归档页波浪曲线与卡片重构 (`css/archive.css`)
- **波浪曲线与节点**：
  - 浅色模式正弦曲线 `wave-line` 采用天青微蓝 `rgba(2, 132, 199, 0.22)`；
  - 滚动进度 `wave-progress` 采用科技蓝 `#0284c7` 配合 `drop-shadow` 辉光；
  - 年份标 `wave-year` 浅色模式为白底磨砂胶囊 + 黑色等宽字体，增加 `.wave-year:empty { display: none !important; }` 消除无文字时的空药丸残留。
- **文章卡片 (`.arc-card`)**：
  - 浅色模式继承 `.bento-card` 通透磨砂玻璃语言，悬浮提供 `transform: translateY(-4px)`、微晶蓝轮廓环与柔和景深阴影；
  - 标题 `.arc-title` 在浅色下为 `#0f172a`，悬浮高亮为 `#0284c7`。

### 2.3 照片墙与灯箱全量适配 (`css/gallery.css`)
- **照片瓷砖 (`.gal-tile`)**：
  - 浅色模式采用白底超细微晶边框与柔和投影，悬浮具备微缩放 `transform: scale(1.035)`；
  - 图片底部说明条 `.gal-cap` 在浅色下采用通透渐变白底与深黑文字，保证触摸屏常驻可读性。
- **灯箱弹窗 (`#gal-lightbox`)**：
  - 背景遮罩支持毛玻璃模糊；
  - 浅色模式弹窗面板为纯白磨砂，大图容器采用浅石板底色 `#f1f5f9`；
  - 底部控制条与切换按钮自适应明暗对比，支持 `Esc` 键退出与键盘左右切换。

### 2.4 主题统一控制与轻量化构建 (`js/subpage.js` & `archive.html` / `gallery.html`)
- **主题切换引擎**：
  - 在 `js/subpage.js` 中新增 `initTheme()`，支持与首页完全一致的 `sj.theme` 本地持久化与 View Transitions 射线圆形扩散动画；
  - 在两页顶栏均内联了零依赖的 SVG 太阳与月亮主题切换按钮；
  - 运行 `node scripts/build-bundles.mjs`，重新编译生成 `js/bundles/sub.js`。

## 3. 视觉验证与自动化测试

通过 Playwright 驱动真实 Chrome 浏览器，在桌面端（1440×1000）与移动端（390×844）全量执行端到端对比与交互测试：

| 测试项 | 浅色模式验证 | 深色模式验证 | 移动端响应式验证 |
|---|---|---|---|
| **归档页 (`archive.html`)** | 标题/卡片/胶囊对比度 100% 达标，波浪线与年份标清晰 | 保持极夜星空深邃氛围，高亮霓虹蓝反馈 | 单列垂直时间线折叠完美，点线对齐 |
| **照片墙 (`gallery.html`)** | 瓷砖磨砂白底与说明条文字高对比，边框清晰 | 深黑暗房风格，悬浮微光轮廓 | 自动退化为单列瀑布流，无横向溢出 |
| **灯箱弹窗 (`#gal-lightbox`)** | 浅色磨砂控制条与高对比操作键，Esc 正常关闭 | 暗色背景与高透控制条，Esc 正常关闭 | 视口自适应，大图居中展示 |
