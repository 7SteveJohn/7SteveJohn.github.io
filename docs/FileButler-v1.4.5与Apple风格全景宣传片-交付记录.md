4. **100% 事实与官方仓库核验（零虚构功能、零错误介绍）**：
   - 全片嵌入 `7SteveJohn/FileButler` 官方仓库全部 **5 张真实桌面界面截图**（`01-dashboard`、`02-files`、`03-organizer`、`04-settings`、`05-knowledge`）与官方档案柜图标；
   - 所有功能严格对齐 `README.md`、`README.zh-CN.md` 与 `v1.4.5` Release Notes：

     - **多维秒搜**：支持 `ext:`、`size:`、`dm:`、`path:`、`cat:` 高级语法与关键词自由混写，长词走 SQLite `FTS5` 全文索引，中文名支持全拼与拼音首字母匹配（如 `bg → 报告`），照片（含 iPhone `HEIC`、`TIFF`）优先读取 `EXIF` 真实拍摄时间，支持列表 / 网格 / 时间线三视图；
     - **`v1.4.5` 窗口内全预览与结构化识图**：新增 `mp3 / wav / flac / ogg / m4a / aac` 内置播放与 `zip / tar / gz / tgz / bz2 / xz` 免解压只读目录树预览，音视频支持 `127.0.0.1` 白名单服务下的 `HTTP 206 Range` 拖动进度条秒响应；接入 `Xiaomi-OCR-0`（0.8B）结构化解析扫描版 PDF（保留表格行列结构、数学公式转 LaTeX、按阅读顺序输出），无视觉模型时自动回退 Windows 系统自带 OCR，支持可选 `qwen2.5vl` 图片语义搜图；

     - **先预览后执行与空间回收**：智能整理支持扫描表逐行下拉微调目标分类、生成原路径→目标路径预览清单、重名自动递增 `(1)` 防覆盖、事务日志整批一键撤销/重做，以及 `v1.4.5` 新增的 `{date}` / `{parent}` / `{name}` / `{seq:03}` 模板批量重命名；三级精确哈希 + 64 位 `dHash`（11 段不重叠切片零漏检）相似图片检测支持组内并排对比点选保留项，配合 `v1.4.5` 新增的「待清理区」空间管理面板一键移入系统回收站；
     - **硬件探测荐模与隐私自主**：自动探测内存与显卡显存推荐 `Qwen3`（`4b / 8b / 14b / 32b`）模型、默认 30 分钟常驻显存、支持自定义模型存储盘符；支持免密钥直连 `LM Studio` 或选配 OpenAI 兼容云端 API（内置 DeepSeek / GLM / Kimi / 千问等预设），并支持「对话走云端、向量留本地 `bge-m3`」独立混搭，兼顾原生 `Alt+Space` 全局热键（默认关闭）、中英双语、四套主题与每日自动备份（保留最近 5 份）。
