## 一、 重制背景与真立绘升级架构

此前 v2.0 临时采用的纯代码 SVG 几何拼贴方案在二次元插画质感、发丝层次、瞳孔高光与衣褶体积感上无法达到工作室商业立绘水准；而早期 v1 版 Live2D 方案又存在四项历史遗留缺陷：
1. **单图切分太阳穴撕裂与头部锁死**：旧版 `chunk/index2.js` 因单张原图缺少脸廓与后发补底，在 `update()` 中硬编码 `setParameterValueById(ParamAngleX, 0)`，导致角色头部无法随光标自然偏转。
2. **表情索引类型错配静默失效**：旧版调用传入整数索引，而 Cubism 运行时 `_expressions` 按字符串键名检索，导致表情切换长期静默失效。
3. **遗留 `#waifu` / `#live2d` 样式污染与首帧闪烁**：旧版全局样式强制写入 `680px !important`，且纹理异步上传期间存在空白帧闪烁。
4. **系统动效开关误杀**：Windows 性能优化环境开启「减弱动画效果」（`prefers-reduced-motion: reduce`）后，旧版门控直接阻断了动态模型加载。

本次 **v3.0 真立绘化重做** 在 `100%` 保留 v2.0 极简现代外壳（悬停快捷操作丸栏 `.sjc-dock`、札签拆包/翻牌联动气泡 `.sjc-bubble`、左下/右下双角零碰撞分流、`<7>` 猫耳折叠徽标）的基础上，将舞台内核彻底升级为 **工作室精绘多层原画 + `PSD2Live` Cubism 5 `.moc3` 骨骼绑定 + 自研零污染 WebGL2 超采样适配器**：

- **工作室级日系赛璐璐多层立绘与 `.moc3` 物理骨骼（`7steve_v2`）**：由 24 层去白边（Alpha Decontamination）精绘部件编译为 `7steve_v2.moc3`（`337KB`）与 3 张 `4096` 图集单通 `q92` WebP 纹理，补齐完整脸廓底板与后发深度层，配合 3 段前发与 4 段双马尾钟摆物理（`7steve_v2.physics3.json`），彻底根除转头破洞与明暗背景边缘杂色光晕。
- **零闪烁渐进显形（Zero-Flash Progressive Reveal）**：第 `0` 帧即刻呈现去杂边高清静态立绘 `7steve-v2-static.webp`，后台异步拉取 `live2dcubismcore.min.js`、`chunk/index2.js` 与模型纹理；待 Cubism 状态机完成全部纹理上传（`_state >= 22`）并连续绘制 2 帧实画面后，以 `0.38s` 丝滑交叉淡入切换至实时 WebGL2 画布，全程零空白帧、无 WebGL2 环境自动常驻高清静态立绘。
- **2.25x–3.0x 超采样 Retina 渲染与高精度遮罩**：画布缓冲区按 `devicePixelRatio` 动态超采样（如桌面 `224×298px` CSS 舞台对应 `538×715` 物理像素帧缓冲），并将 Cubism 裁剪遮罩升级至 `1024px` + 各向异性过滤，确保斜向发丝、眼镜框与全息板文字在 2x/3x 高分屏下锐利通透。
- **绕过系统 `prefers-reduced-motion` 误杀 + 收起态 `0%` 开销**：不再因 Windows 系统级减弱动画开关降级为死图；同时在折叠为右下角 `42px` `<7>` 猫耳徽标或标签页切入后台时，立即调用 `cancelAnimationFrame` 彻底挂起 WebGL2 渲染循环，实现后台 `0%` CPU/GPU 占用。
