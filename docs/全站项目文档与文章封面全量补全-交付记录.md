# 全站项目文档与文章封面全量补全 · 交付记录

## 1. 交付背景与问题根因

在上一轮修复中，系统为博客文章（`posts/*.md`）中的 17 篇手记生成了深空风格的 SVG 矢量封面。但在全面审查中发现，站点的**项目文档（`PROJECTS_DATA` 及弹窗）**与关联文档体系中仍存在多处封面缺漏与不一致：

1. **项目文档详情缺失封面图**：
   - `gameboost`（GameBoost · 打游戏前点一下）与 `gameboost-dlssg`（GameBoost-DLSSG · DLSS 帧生成）在 `js/projects.js` 中的 `details` Markdown 文本缺少像其他项目一样的实机界面图与说明标注，导致读者在点击「查看详情」时正文顶部一片空白，缺少实机截图。
   - `openProjectModal` 在项目详情弹窗中未配置顶层封面保底渲染逻辑，当 `details` 未显式嵌入图片时没有自动注入封面横幅。
2. **项目对应手记的封面风格不一致**：
   - 对应项目的技术手记 `posts/filebutler-local-rag.md` 与 `posts/gameboost-frame-pacing.md` 之前沿用旧有的 WebP 截图，未纳入 `scripts/gen-covers.mjs` 的 16:9 高清深空矢量封面体系，导致与全站其余 17 篇技术手记的深空科技感风格不统一。
3. **连载小说书架封面缺漏**：
   - `posts/novel/sample-night/` 章节元数据中未声明 `bookCover`，导致 `js/novel-data.js` 生成的封面为空，在 `novel.html` 书架上回退显示单字占位符。
