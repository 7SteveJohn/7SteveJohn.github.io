# 全站项目文档与文章封面全量补全 · 交付记录

## 1. 交付背景与问题根因

在上一轮修复中，系统为博客文章（`posts/*.md`）中的 17 篇手记生成了深空风格的 SVG 矢量封面。但在全面审查中发现，站点的**项目文档（`PROJECTS_DATA` 及弹窗）**与关联文档体系中仍存在多处封面缺漏与不一致：

1. **项目文档详情缺失封面图**：
   - `gameboost`（GameBoost · 打游戏前点一下）与 `gameboost-dlssg`（GameBoost-DLSSG · DLSS 帧生成）在 `js/projects.js` 中的 `details` Markdown 文本缺少像其他项目一样的实机界面图与说明标注，导致读者在点击「查看详情」时正文顶部一片空白，缺少实机截图。
   - `openProjectModal` 在项目详情弹窗中未配置顶层封面保底渲染逻辑，当 `details` 未显式嵌入图片时没有自动注入封面横幅。
2. **项目对应手记的封面风格不一致**：
   - 对应项目的技术手记 `posts/filebutler-local-rag.md` 与 `posts/gameboost-frame-pacing.md` 之前沿用旧有的 WebP 截图，未纳入 `scripts/gen-covers.mjs` 的 16:9 高清深空矢量封面体系，导致与全站其余 17 篇技术手记的深空科技感风格不统一。
3. **连载小说书架封面缺漏**：
   - `posts/novel/sample-night/` 章节元数据中未声明 `bookCover`，导致 `js/novel-data.js` 生成的封面为空，在 `novel.html` 书架上回退显示单字占位符。

## 5. 补充修复：SVG 根因排查（XML 实体转义与尺寸定义）

在用户反馈文章卡片仍偶现「蓝底单字母 A」回退现象后，通过 Playwright 端到端浏览器抓取与网络诊断，定位并解决了关键底层隐患：

### 5.1 根因定位
1. **XML 实体未转义（关键原因）**：
   `scripts/gen-covers.mjs` 在生成 SVG 模板时，英文标题直接插值为 XML 节点文本。包含 `&` 符号的标题（如 `Strengths & Bottlenecks`、`Token & Context Window`、`Compute, Embodied & Ethics`、`Rules Engine & Linting` 等 10 个封面）因 XML 规范未对 `&` 进行实体转义，导致 Chrome 的 XML 渲染器抛出语法错误：
   `error on line 48 at column 164: Unexpected token inside entity`
   导致 Chromium 解码图片失败并触发 `<img>` 的 `onerror` 事件，进而执行 `onerror="this.remove()"` 将图片节点从 DOM 移除，回退显示首字字母「A」。
2. **SVG 缺少固有物理尺寸**：
   原始模板使用 `width="100%" height="100%"`，缺少绝对像素宽高，在 Chromium 中导致 `naturalWidth: 0`。
3. **Service Worker 缓存留存**：
   客户端 Service Worker 在 `sevenjohn-v192` 缓存版本下未能及时刷新最新的 SVG 资源。

### 5.2 实施修复
1. **实现 XML 安全转义**：
   在 `scripts/gen-covers.mjs` 中增加 `escapeXml` 函数，对 `titleEn`、`titleCn`、`tag`、`num` 严格执行 `&` -> `&amp;`、`<` -> `&lt;`、`>` -> `&gt;` 转义。
2. **确立固定尺寸属性**：
   将根节点改为 `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 640 360" width="640" height="360">`，确保 `naturalWidth: 640, naturalHeight: 360`，提供稳定的固有高宽比。
3. **全量重新生成与校验**：
   编写 `scripts/check-all-svgs.mjs`，通过无头 Chrome 对全部 24 张 SVG 封面逐一执行 XML DOMParser 解析，确认 24/24 均为合法且 0 语法错误。
4. **Service Worker 版本升级**：
   在 `sw.js` 中将缓存版本推进至 `sevenjohn-v193`，确保客户端自动更新拉取最新的 SVG 产物。
