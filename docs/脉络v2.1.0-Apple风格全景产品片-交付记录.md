## 一、 创作与真实性约束落实

1. **独立原创 Apple Keynote 产品片视觉体系（零套用旧模板）**：
   - 采用 Cupertino 经典的 **「宣纸石白 `#F5F5F7` ⇄ 深邃曜石 `#070A11`」** 昼夜摄影棚切换、大字号紧凑字距主标题（`Inter` 可变字体 + Tabular 等宽数字）、拉丝钛金属 3D 手机硬件模型（严格按实机截图 `900×1500` `3:5` 比例无损呈现，零裁切顶栏与底栏）以及尾声标志性的 **10 格 Bento 全景总览墙**。
2. **时长达标（1 分 38 秒 / 98.0 秒）**：
   - 全片锁定 `96 BPM`（每小节 `2.50s`，共 `39.2` 小节 = `98.00s`），共设 **6 幕 13 镜**，所有镜头转场与动效起落严格对齐音乐小节强拍。
3. **100% 原创多乐章立体声配乐（48kHz Stereo 物理建模合成）**：
   - 围绕 `Dmaj9 → Aadd9/C# → Bm11 → Gmaj9` 现代简约和声进行原创编曲：融合毛毡钢琴（羊毛槌瞬态 + 琴弦非谐泛音）、冕牌水晶钟琴泛音琶音（呼应 Liquid Glass 液态玻璃折射主题）、温暖模拟合唱弦乐垫、深沉 Sub-Bass 与克制的极简木边击打律动，经立体声 Schroeder 混响与母带软限幅归一至约 `-13.6 dBFS RMS`。
4. **100% 事实与源码核验（零虚构功能、零错误数据）**：
   - 全片嵌入 `7SteveJohn/netops-handbook` `v2.1.0` 仓库内全部 **8 张真实实机截图**（`01-home`、`02-textbook`、`03-module`、`04-faults`、`05-dict`、`06-cli`、`07-interview`、`08-profile`）与真实应用图标；
   - 所有指标与命令逐字核对官方 `README.md` 与 `app/src/main/assets/native-data.json`：
     - 定位如实表述为「配合教材、网课与真机实验使用的随身辅助工具」，**完全离线、零系统权限声明、不注册、无广告、打开即用**（不绑定固定安装包体积表述，便于后续持续迭代）；
     - **运维教材全书**：`12 大领域 · 50 章 · 1,003 小节 · 约 120 万字`，含顶部 H2 小节冰晶胶囊快跳条、断点续读与 `< 0.3 ms` 中文 2-gram + 拉丁词倒排索引秒搜；
     - **原生光学架构**：Jetpack Compose 全原生重构 + AGSL 实时凸透镜色散折射（`1.37×`），「极致 / 标准 / 无」三档液态玻璃，「悬浮胶囊 ⇄ 原生贴底」双态导航，切页 `99th 30ms`，`22 张`横竖屏成对壁纸 + 相册自选；
