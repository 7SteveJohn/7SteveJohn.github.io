## 0. 核心四要素决议（已根据 7steve.jpg 视觉设定与站点形态敲定）

- [x] **构图：半身像（头顶至卫衣下摆/腰部，含双手持全息屏）**
  - **定案理由**：站点右下角展示容器严格限制在 `300×300` 像素内。若使用全身像（如原画长腿及短裙鞋袜），缩放到 300px 高度时面部仅占约 35–45px，黑框眼镜、眨眼、视线追踪（ParamEyeBall）等核心神态在普通屏幕与高刷屏上将严重缩水变糊；改用半身像（头顶发光猫耳至卫衣下摆），面部尺寸提升至 ~140px，兼具双马尾物理摆动、发光猫耳、全息悬浮屏与小机械猫的完整视觉冲击。
- [x] **画风与比例：正常日系二次元比例（头身比约 1:5.5，完美承袭 7steve.jpg 原画）**
  - **定案理由**：楠屿札记走的是「深空暗色系 + 本地 AI 工具极客风」，正常比例的极客技术少女形象比低幼 Q 版更贴合站点「本地推理场 / 开发手记」的硬核气质。
- [x] **互动范围（全交互链路已对齐）**：
  1. **常态怠速**：自然呼吸（ParamBreath）、灰蓝双马尾微风物理摆动、卫衣抽绳自然晃动、猫耳呼吸灯微弱脉冲。
  2. **视线与转头**：眼球视线跟随鼠标（ParamEyeBallX/Y）、头部三轴微转（ParamAngleX/Y/Z）、身体随动（ParamBodyAngleX/Z）。
  3. **点击身体（tapBody）**：食指轻触全息屏弹出蓝光涟漪，或单手轻扶黑框眼镜，伴随元气笑容。
  4. **摸头/点击猫耳（flickHead）**：猫耳抖动并高亮闪烁，闭单眼吐舌俏皮表情。
  5. **左上角赛博猫伙伴**：独立悬浮呼吸晃动，鼠标悬停时屏幕表情切换为 `^._.^`。
- [x] **模型格式：Cubism 4/5 格式（首选 `.model3.json` + `.moc3`，兼顾 Cubism 2 兼容导出）**
  - **定案理由**：现代 Cubism Editor 4/5 导出物理模拟、表情权重融合更加平滑。站点底层已具备 Cubism 5 与 Cubism 2 的无缝接入链路。

### 针对 7steve 的 5 大关键补画防穿帮红线（务必对齐画师/拆分师）

1. [x] **黑框眼镜遮挡下 100% 完整补画**：镜框下方的额头、眼皮、睫毛、眼球必须完完整整绘制。转头或闭眼时若镜框内透空将直接导致严重视觉 BUG。
2. [x] **全息交互屏背后的卫衣与字样补齐**：手中全息屏为 60% 半透明材质，其后方遮挡的深蓝卫衣布料褶皱、白色口袋线以及 "7steve" 胸标必须完整平涂补齐。
3. [x] **双马尾转头露空区补齐**：灰蓝渐变双马尾左右摆动幅度大，发束被甩开时会露出耳后根部、头梁两侧及后脑勺，底发与兜帽阴影需留足覆盖余量。
4. [x] **口腔全结构补齐**：开闭嘴不仅是线条伸缩，张嘴时需完整包含上排牙齿白边、粉色口腔壁与舌头，不可留透明空洞。
5. [x] **四周透明余量**：所有活动肢体部件边缘至少保留 8–12px 的羽化/过渡余量，防止网格旋转拉伸时出现截断黑边。

## 3. 绑定工程（Cubism CMO3）参数规范

- [x] **基础视角**：
  - `ParamAngleX` (-30 ~ +30)：头左右转
  - `ParamAngleY` (-30 ~ +30)：头上下仰俯
  - `ParamAngleZ` (-30 ~ +30)：头侧倾
  - `ParamBodyAngleX` (-10 ~ +10)：身体左右倾
  - `ParamBodyAngleZ` (-10 ~ +10)：身体侧倾微动
- [x] **眼睛与视线**：
  - `ParamEyeLOpen` / `ParamEyeROpen` (0.0 闭眼 ~ 1.0 睁眼 ~ 1.2 惊喜睁大)
  - `ParamEyeBallX` / `ParamEyeBallY` (-1.0 ~ +1.0 鼠标追踪核心参数)
  - `ParamBrowLY` / `ParamBrowRY` (眉毛上下)
  - `ParamBrowLAngle` / `ParamBrowRAngle` (眉毛倾斜)
- [x] **嘴部与说话**：
  - `ParamMouthOpenY` (0.0 闭嘴 ~ 1.0 开口说话)
  - `ParamMouthForm` (-1.0 嘟嘴 ~ +1.0 弯嘴角微笑)
- [x] **物理演算钟摆组（Physics）**：
  - `Group 1: Hair_Twintail_L`（左马尾 2 级串联摆动，阻尼 0.85）
  - `Group 2: Hair_Twintail_R`（右马尾 2 级串联摆动，阻尼 0.85）
  - `Group 3: Hair_Front`（前额三片刘海软摆动）
  - `Group 4: Hoodie_Strings`（左右卫衣抽绳物理轻晃）
  - `Group 5: Pet_Cat`（赛博猫悬浮微波浪起伏）
- [x] **特征扩展参数**：
  - `ParamCatEarTwitch` (0.0 ~ 1.0 猫耳受刺激抖动)
  - `ParamCatEarGlow` (0.2 ~ 1.0 呼吸灯发光亮度调节)
  - `ParamHoloGlow` (0.4 ~ 1.0 全息屏被点击时的泛光涟漪)
