## 二、能学的（可直接迁移，零依赖、不破本站红线）

1. **键盘快速跳转面板**（3:09 那段）。按住修饰键弹出栏目与条目列表，松手落到选中项。本站只有导航 + ScrollSpy，长页面仍要滚；这个用 keydown + 面板 + 方向键高亮 + `scrollIntoView` 就能做，不引外链。
2. **文章模态内的阅读进度条**（1:00）。本站文章是 modal 打开，取 `panel.scrollTop / panel.scrollHeight` 驱动面板顶部一条细线即可。
3. **卡片依次错落入场**（0:44 起）。本站 `.reveal` + `--reveal-delay` 已经具备能力，只是没按下标错开：索引 × 60–80ms。
4. **卡片 hover 3D 倾斜跟随鼠标**（0:53）。mousemove 归一化坐标 → `rotateX/rotateY` + transform 过渡；移动端不启用。本站卡片是接近满屏的大卡，倾斜幅度要压到 1–2°，否则会和一屏一产品的稳定版式打架。
5. **未播放时显示内容**（0:30）。他放「随机一言」，本站不能放金句（文案红线），可换成功能性文字：曲目数、当前歌单名。

## 三、不该学的（与本站气质或约束冲突）

- **鼠标轨迹 / 点击特效 / 季节特效 / 星星迸发**：与全站克制基调、唯一强调色冲突。
- **背景图 + 模糊度滑块**：本站背景是程序化 3D 场景，暴露模糊度要动渲染层，收益低。
- **时光轴归档**：9 篇手记的量撑不起横向惯性时间轴。
- **阅读量 / 评论数统计、GitHub OAuth 评论**：都要后端 + 第三方脚本，与「零外链、依赖全自托管、纯静态」直接冲突。访问量继续看 GitHub Insights。
- **pure-admin 式后台**：6 张卡 + 9 篇手记的规模，`projects.js` + 生成脚本已经够用，上后台等于多养一套要维护的东西。

## 四、真正值得抄的是内容习惯

他自己把踩过的坑写成了文章：《Framer Motion 动画实战：从 52 个组件中总结的 11 种动效模式》《从零搭建一个全栈博客：Next.js + FastAPI + Vue》《记一次让人崩溃的部署踩坑：Nginx 缓存引发的血案》—— 标题直白，内容是「我做了什么 + 撞到什么墙」的原始记录。

本站的「技术手记」栏目可以照此沉淀已有的经验：液态玻璃那 6 个面怎么定的、一屏一产品翻页为什么从 38% 线改成位置阈值、SW 全面 stale-while-revalidate 那次改造踩了什么。这类记录比功能清单对读者有用，也正好补上栏目数量。

## 五、总账

他做的是**内容运营型博客**（后台 + 数据库 + 登录 + 社交互动），本站做的是**作品集 + 手记型静态站**。复杂度差异来自定位，不是水平差异。可迁移的是交互细节（键盘跳转、阅读进度条、错落入场、3D 倾斜）和内容习惯（把踩坑写成文）；后端与后台那一套，本站不需要。

## 附：那套音乐 API 的来路（2026-10-16 追问补充）

**链路**：`<meting-js server="netease" type="playlist" id="...">`（MetingJS 自定义元素，UI 是 APlayer）→ 把 `meting_api` 指到自己的后端地址（约定参数 `server / type / id`）→ 后端去调网易云的 weapi / eapi（RSA + AES 混淆、请求签名）→ 取回歌单、歌曲信息、歌词、播放直链 → 前端播放。

**获取方式三种**

1. **自部署**（最常见）：PHP 版 Meting 丢进虚拟主机；或用社区维护的 Serverless 版（Cloudflare Workers / Vercel 一键部署，Hono + @meting/core）。取 VIP 资源要带 `METING_COOKIE_*`，QQ 音乐 Cookie 还得靠 KV + Cron 定时保活。
2. **蹭公共实例**：网上流传的免费 Meting API 地址。随时挂、限流、被清，不适合当唯一来源。
3. **跑在自己服务器上**：视频作者有国内服务器，但视频里没展示他怎么部署的，只说「MetingJS 包装了网易云 API」。

**花钱吗**

- 代码层面全免费：MetingJS / Meting / APlayer 都是许可证宽松的开源项目。自部署用免费档（CF Workers、Vercel 或便宜虚拟主机）对个人博客的量级够用 —— 所以「不额外花钱」是做得到的。
- 市面上确实有人卖「音乐解析 API」，那买的不是技术，是风险。
- 真正的成本不是钱：网易云没有面向个人开放「取播放直链」的官方接口（官方开放平台走的是 IOT、游戏联运、网页应用接入，要申请审核）。这条链本质是逆向 weapi / eapi 的盗链。网易云此前已向 NeteaseCloudMusicApi 发过法律通知，要求下线盗链方法与内容，该项目随后删库停更。

**对本站的结论**：`music/` 里自托管 11 首曲目不依赖任何外部 API，也没有上述风险，不该换。要扩曲库就走自由许可的音乐。

### 2. 可直接抄的动效参数（68s 画面里的源码原文）

```
PhotoCard 入场与 hover：
initial    { opacity: 0, y: 30, rotate: rotation * 2 }
animate    { opacity: 1, y: 0,  rotate: rotation }
transition { duration: 0.6, delay: index * 0.08, ease: "easeOut" }
whileHover { rotate: 0, scale: 1.03, zIndex: 10,
             transition: { type: "spring", stiffness: 300, damping: 20 } }

评论卡入场：
transition { duration: 0.4, delay: idx * 0.05 }
```
两句他自己的注解值得记：每张照片有一个随机 `rotation`（如 1.5°），**入场时从 `rotation * 2` 的角度落下来**（超调 → 落定）；同一套参数在 `messages/page.tsx`、`moments/page.tsx` 里完全复用。

要点：① 入场是超调（起点比目标更远，落定即目标）；② 错落间隔 50–80ms × 索引。本站把 `spring(stiffness 300, damping 20)` 近似成 CSS 用 `cubic-bezier(.34,1.56,.64,1)`。
